# field_check — 10-02 현장 즉석 확인

체크리스트 A1·A3·A4·A5와 멈출 신호용. 사진 1장 2초 안팎(200MP).

```
# 1) A3 사진 1장으로 좌표 눈금 그림 만들기
conda run -n aiffel python field_check.py grid 사진.jpg      -> 사진_grid.jpg

# 2) site_template.json 을 site.json 으로 복사해 roi 4개 숫자 채우기

# 3) 확인
conda run -n aiffel python field_check.py check site.json 사진.jpg [사진2.jpg ...]
   -> 표(샤프트 px, 핀 px, 각 sd, 배경 포화 %, 대비) + 사진_check.jpg(경계 점 찍은 확대 크롭)
```

| 단계 | 넣을 사진 | 볼 것 |
|---|---|---|
| A1 | 백라이트만 | 포화 % (1% 넘으면 경고) |
| A3 | 차광 후 1장 | 사진_check.jpg 에서 점이 실루엣 가장자리에 붙었나, sd 경고 없나, 샤프트 px 400 이상, 번짐(px) 확인 |
| A4 | 연속 3장 한꺼번에 | [A4] 표 — 첫 장 대비 0.1% 이내 |
| A5 | "중" 시편 | site.json 에 `true_shaft_mm` 실측값 -> [A5] 환산·핀 이동 안내 |
| 경계 단면 (3차 촬영 2단계) | 아래 가림 있는 것·없는 것 몇 장 | [경계 단면] 표와 사진_profile.png. 아래(빨강)가 위(파랑)처럼 단 1개, 폭이 위의 2배+2px 안이면 "깨끗함". 아니면 판정 "다시 세팅" |
| 블록 B~ | 시편마다 1장 | site.json 에 `ref_pin_px`(A4 기준값) 적어 두면 매번 기준 대비 % |

- 핀 방식 2(눕힘)면 `"axis": "v"`
- 경고 `경계를 찾은 줄이 …뿐` -> ROI 에 받침·핀 끝(모따기)이 섞임. 고른 구간으로 좁힌다
- 경고 `pin: 좌우 경계 번짐` -> 핀 한쪽에 밝은 테두리(광택면 반사). 핀 px 변화(A4)는 그대로 쓰고, A5 는 이동 안내 없이 값만 기록
- 경고 `줄마다 폭 흔들림` -> 반사 띠·테이퍼·먼지. 10-01 집 사진(140524)에서 세운 핀 옆면 회색 반사 띠로 9% 흔들림이 나왔다

경계 단면 읽는 법
- 가로축 = 50% 경계에서 떨어진 px(왼쪽 샤프트 안, 오른쪽 배경). 위·아래를 같은 방향으로 맞춰 겹쳤다
- 폭 = 안쪽 10% ~ 바깥 90% 거리, 단 = 밝기가 가파르게 오르는 곳 수
- 기준을 바꾸려면 site.json 에 `"bottom_clean": [배수, 여유px]` (기본 [2.0, 2.0]), 창 크기는 `"profile_half_px"` (기본 60)
- 10-08 사진 13묶음(묶음마다 첫 장, 베어링부 ROI): 위 폭 2~7px·단 1개(NO10 하나만 2개), 아래 폭 62~70px·단 1~3개 -> 13묶음 전부 "아래 여러 단/넓음". `1012_edgecheck` 눈 확인과 같은 결과
- 같은 단면으로 핀(Ø10)을 보면 핀 아래도 약하게 같은 모양(안쪽 0.15 띠, 바깥 작은 단, 폭 25~33px)이 보였다. 10-12 눈 확인에서는 핀이 깨끗하다고 봤다. 아래쪽 공통 현상일 수 있어 3차 촬영에서 같이 본다
- 약한 곳: 폰 사진은 선명화 처리로 경계 바깥에 밝게 튀는 곳(1.05)·작은 골이 생긴다. 이게 '단'으로 세어질 수 있다. 그림을 같이 볼 것

검증: `test_field_check.py` (합성 사진으로 소수점 폭 ±0.05px, 0.1% 변화 검출, ROI 끝 어두운 물체, A5 환산·이동 방향, 경계 단면 깨끗함/아래 띠+단 구별 — 전부 통과)
