# 01. 문제 정의 · 목표 · 범위 밖

## 대상

원전기계(주) 자동차 조향장치용 샤프트. 외경 **Ø20.02 ±0.01 mm** (허용 20.010~20.030), 중요 특별특성.
현재 사람이 게이지에 물려 읽고 판정하고 일지에 적는다. 2026년 11월 품질경영시스템 인증 심사 예정.

## 목표 (09-11 재정의, 09-16 데이터로 확인)

주목표: **공정 이상 조기검출** — 가공 누락·정삭 누락처럼 규격에서 크게 벗어난 부품을 촬영 즉시 잡고 기록을 자동으로 남긴다.
받침 1: 반복 촬영으로 측정 산포(σ)를 실측해 판정 문턱(회색지대 = k·σ)을 정한다.
받침 2: 측정 상수를 설정 파일로 뺀, 장비에 종속되지 않는 측정 엔진.

## 범위 밖 (명시)

- **±0.010 mm 공차 합/불 판정.** 09-16 데이터로 확인: 정상품 12개의 실측 폭 34µm가 현재 1픽셀(34.7µm)이다. 공차 판정은 게이지가 한다
- 양산 설비 PLC 연동, 자동 로딩
- 독립 검증 데이터 없는 상태의 검출률 % 주장

## 왜 이렇게 정했나

카메라로 ±10µm를 판정하려면 측정 σ가 1µm(AIAG 조건부) 이하여야 한다. 텔레센트릭 + 라인스캔 논문도 σ 2µm 수준으로 불합격이다.
비전은 게이지의 경쟁자가 아니라 분업 상대다: **판정은 게이지, 이상 검출과 기록은 비전.**
