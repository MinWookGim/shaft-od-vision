# 2026-09-12 한계 탐색 실험 — 새 촬영 없이 지금 시스템의 한계를 재다

7/9 사진 10장 + 기존 YOLO 모델만으로 실험했다.

## 나온 것

1. **측정 시스템 sd = 30.1µm** — 정상품 7장(서로 다른 개체)의 비전값 폭 81µm vs 계측기 폭 2µm에서 낸 값. 공차 전폭의 1.5배. 개체 간 값이라 재현성 σ는 아니다
2. **회색지대는 k=3이 하한** — k=2면 정상품 1/7이 헛경보
3. **조용한 실패** — 7/9 NG01이 9.2mm 틀렸는데 유효점 31/31, conf 0.701로 아무 신호가 없었다. 경로: 박스 커짐 → ROI 커짐 → 허용 지름 상한 커짐 → 배경 엣지를 `max(지름)`이 집음
4. **측정값을 정하는 건 샤프트가 아니라 상수 셋** (vertical_margin, strength_keep, gradient 백분위)
5. **YOLO는 외운 게 아니다** — 학습 사진 34.7µm vs 처음 보는 사진 37.6µm. 투자처는 파인튜닝이 아니라 광학·지그·측정 로직
6. **덧셈 바이어스 +3.34px** — 합성 막대에서 모든 지름이 일정하게 크게 나온다. 지금은 캘리브레이션과 상쇄되지만 2점 캘리브를 넣으면 깨진다

## 이어서 한 실험

- **박스 민감도**: 박스를 1.5%(상하 10px) 흔들면 10장 중 4장 폭주. 상하가 좌우보다 수십 배 위험
- **촬영 조건**: JPEG는 문제 아님(품질 40까지 9.3µm) · 해상도 하한 0.75배 · 대비는 밝은 쪽이 약 46배 위험(대비 1.6에서 292.1µm vs 0.6에서 6.3µm, 노출 과다 주의)

## 가설 하나가 반증됐다

"다섯 증상이 `max(지름)` 한 줄에서 나온다"고 봤는데, 선택 규칙을 바꿔보니 **실사진 MAE가 36배 나빠졌다.**
실사진에는 홈·단차·가공무늬가 있어 내부 엣지가 외곽보다 셀 때가 있다. `max(지름)`은 필요한 규칙이었다.
합성 실험만 믿고 고쳤으면 측정기를 망칠 뻔했다. → 검증 단계를 따로 두는 이유.

## 진짜 범인 — 허용 지름 범위의 기준

범위를 ROI 높이 비율로 잡은 것이 문제였다. **박스 높이 기준(0.55~0.95)** 으로 바꾸니 7개 축 중 6개 개선, 악화 0.
7/9 NG01 29.82 → 20.47mm (실측 20.603). 정상품 값은 그대로.
기본값은 바꾸지 않고 옵션(`dia_basis`)으로만 넣었다.
