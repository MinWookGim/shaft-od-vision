# 2차 촬영(10-08) 분석 정리 — 10-09 ~ 10-12

10-08 원전기계 본촬영 130장을 여러 방법으로 다시 분석한 결과와, 선행 개발자 결과보고서(10-10)를 같은 사진으로 재현해 확인한 결과를 한곳에 모았다. 숫자는 [02_facts](../02_facts.md) 「2026-10-08 2차 촬영」 절에 있다. 코드와 결과 파일은 [experiments/20261008_2차촬영](../../experiments/20261008_2차촬영/)에 있다.

---

### 1. 데이터
- 13묶음 × 10장 = 130장. 정상 10개(NO1~NO10) + NG 2개 + NO1 재촬영. 사진 한 장 1px 약 37µm (Ø20 = 약 544px)
- 실측: NO1 20.010, NO2 20.020, NO3 20.030, NO4 20.030, NO5 20.020, NO6 20.010, NO7 20.017, NO8 20.019, NO9 20.015, NO10 20.015, **NG1 19.993, NG2 20.002**
- NG 두 개는 규격(20.010~20.030) **하한 아래**다. 정상 평균(약 20.019)과의 차이는 −26µm, −17µm. 사진에서는 0.7px, 0.5px 차이다

### 2. 비교 잣대: 평균 찍기
- 측정 없이 모든 시편을 정상 평균으로 불렀을 때의 오차. 정상 10개를 하나씩 빼고 교정(LOO)하면 **MAE 5.8µm, 최대 12.7µm**
- 정상 시편 실측이 20µm 안에 몰려 있어서 이 값이 작다. 측정 결과는 이것보다 확실히 작아야 측정이 정보를 담았다고 말할 수 있다

### 3. 측정 결과 (팀장 분석)
- 경계 찾는 방법 6종(M0~M5)을 같은 규칙으로 비교: 최선 MAE 15.5µm(50% 밝기 경계). **평균 찍기를 이긴 방법이 없다**
- 핀 측정 자리를 핀 끝 기준으로 맞추면 12.8µm, 묶음마다 마지막 5장만 쓰면 11.1µm. 그래도 못 이긴다
- 같은 시편 10장 반복 sd 4.5~13.8µm (NO7 27.1µm, NG1 20.5µm). 시편을 바꿀 때보다는 작지만, 평균 찍기 MAE(5.8µm)와 비슷하거나 크다

### 4. 원인 진단
| 원인 | 확인한 것 |
|---|---|
| 카메라 이동 | 시편 교체 때 사진 전체가 수 px\~56px 밀렸다. 테이블 밖 기계판도 같이 움직여서 테이블·V블록이 아니라 카메라다. 큰 이동(NO1·NO2 약 50px, NO7)은 폰 조작(화면 바뀜, 초점 다시 잡음) 시점과 겹친다. 메모에 없는 작은 흔들림(수 px, NO6 등)도 있었다. 마지막 초점 재설정(NO7) 뒤로는 7묶음 동안 기계판 기준 −15\~−18px로 안정 |
| 초점 흐름 | NO7은 초점을 다시 잡은 직후 10장 동안 지름이 +69µm 흘렀다 |
| 시편 쪽 오차 | 카메라가 안정한 구간(NO8, NO9, NO10, NO1 재촬영)에서도 오차가 +23, −1, −2, +19µm (sd 13µm). 놓임·아래 경계가 남는다 |
| 아래 경계의 여러 단 | 아래 경계가 2\~3단(6\~13px)으로 나뉜다. 가리지 않은 백라이트 빛이 샤프트 아래를 스쳐서 생긴 것으로 추정한다(근거: 위 경계는 가린 뒤 1단). 원인(조명·표면 반사·렌즈 플레어)은 따로 확인하지 않았다 |
| 핀 측정 자리 | 핀 폭이 핀을 따라 약 1% 변한다(위 경계만 기욺). 고정 열로 재면 카메라가 밀릴 때 핀의 다른 자리를 잰다. 실제 오차원이지만 주원인은 아니다 |
| 해상도 | 사진을 2배 줄여(50MP 상당) 재도 15.5~17.4µm로, 같은 방법을 원본에서 다시 잰 15.4µm와 구별이 안 된다. 4배(12.5MP 상당)는 33.8µm로 나빠진다 |

### 5. 선행 개발자 결과보고서(10-10) 재현 확인
보고서: NO4\~NO6 3점 교정 → NO7\~NO10 40장 검증, MAE 2.34µm, 40/40 OK.

- **재현**: 선행 엔진을 "가장 센 엣지 쌍, 박스 안 넓힘"으로 돌리면 NO4/5/6 px가 550.43/544.89/543.33으로 보고서(550.33/544.86/543.26)와 0.1px 안에서 같고, 검증 4개 평균도 0.0001mm 안에서 같다
- **교정 기울기**: 1px당 2.57µm. 물리 배율(1px 약 36.8µm)보다 14배 작다. 교정 시편 실측 차이 20µm(물리상 0.54px)에 px 차이가 7.07px라서, 놓임·경계 선택 흔들림까지 지름 차이로 들어갔다. 그래서 출력이 교정 평균(20.020) 근처로 모인다
- **같은 나누기의 평균 찍기**: 20.020만 출력해도 MAE 3.5µm, 최대 5.0µm, 40/40 OK. 보고서 MAE와 차이 1.2µm, 시편 4개. 검증 4개의 측정 평균과 실측의 상관은 약 0.30(보고서 값으로 재계산)
- **NG 적용**: NG1 → 20.0198, NG2 → 20.0215. **20장 전부 OK.** 실측은 둘 다 규격 하한 아래
- **코드 수정 방향 7가지**(밝은 띠 제거 형태학 연산 등): 커널·문턱이 원문에 없어서 세로 25px, 밝기 25로 정해 구현했다. 아래 두 줄은 베어링부 자동 탐지 박스 기준. 자세한 표는 [7가지 수정 적용 결과](./2026-10-12_7가지수정_적용결과.md)
  - OPEN·CLOSE, TOPHAT, BLACKHAT, 덩어리 제거, 중앙 mask: px 변화 약 0.3px(최대 0.34px), NG 20장 전부 OK 그대로
  - inRange: 아래 회색 선반을 지워 경계가 안쪽으로 가고(NO4 약 18px, NO5 약 12px), NG는 NG로 보지만 정상 NO7~NO10도 전부 NG(약 20.006)
- **측정 위치(Anchor)**: 보고서 박스(7844, 3468, 8089, 4468) 고정, Anchor 추적, 팀장 쪽 베어링부 자동 탐지 세 가지 모두 px가 약 0.1px 안에서 같다(최대 폭 0.11px). 샤프트가 가로로 누운 원통이라 박스가 옆으로 밀려도 지름이 거의 안 바뀐다. 위치에 따라 동작이 바뀌는 전처리(중앙 mask, inRange)는 고정 박스에서 NO6 px가 568~649로 터졌는데, Anchor를 쓰면 터지지 않았다. 다만 그 결과도 원본보다는 나빴다(Anchor + 중앙 mask 검증 MAE 14.2µm, 정상 40장 중 OK 30)

정리: 위치 자동화(Anchor)와 아래 경계 A/B 후보 진단은 진전이다. 다만 지금 결과는 측정이 정상과 NG를 가른다는 근거가 되지 못한다. 위치가 아니라 경계를 읽는 쪽 문제다.

### 6. 10-12 팀장·선행 개발자 회의에서 맞춘 것
- 업체에 바로 적용할 단계는 아니다. 다음 촬영이 필요하다
- 핀게이지 대신 실측을 아는 기준 샤프트를 같은 높이·깊이로 놓고 대조하는 안이 나옴. 핀을 넣을지는 미결(선행 개발자: 좌표 고정이면 넣든 안 넣든 무관)
- 내부 합격 기준(측정 항목과 기준값)을 정해야 한다
- 멘토 질문은 선행 개발자가 작성(용접 검사를 양산에 넣을 때의 기준)
- 10-16 보고서는 제출만 한다
- 남은 이견: 촬영 전에 폰 고정·초점·조명을 먼저 해결할지(팀장), 같은 조건으로 다시 찍어 재현되는지부터 볼지(선행 개발자). 한 번의 방문 안에서 변수 하나만 바꿔 번갈아 찍는 방식으로 둘을 함께 할 수 있다

### 7. 다음 촬영 세팅 제안
**그대로 둘 것**: 백라이트 + 위쪽 가림, 블루투스 리모컨 셔터, 무거운 테이블과 V블록, 바닥 삼각대(손대지 않을 때 안정), 현장 메모, 시간순 촬영

**바꾸거나 더할 것**
| 항목 | 이유 | 제안 |
|---|---|---|
| 초점 | 시간이 지나면 풀려서 다시 잡다가 카메라가 밀림 | 프로 모드 50MP 수동 초점, 맞춘 뒤 폰에 손대지 않기 |
| 기준물 | 핀은 지름·표면·위치가 샤프트와 다름 | 실측을 아는 기준 샤프트를 나란히 |
| 아래 경계 | 여러 단 반사 | 프라이버시(루버) 필름 붙인 것/뗀 것을 같은 방문에서 번갈아 |
| 놓임 | 시편이 바뀌면 13µm | 같은 시편 3회 이상 다시 놓고 찍기 |
| 측정 위치 | 지그 위치를 표시하지 않음 | 테이프 표시 + 좌표 고정 + Anchor |
| 검증 시편 | 전부 규격 안이라 OK 판정이 의미 없음 | NG·경계 근처 시편 포함 |
| 현장 확인 | 연속 3장만 봐서 시편 교체 사이 이동을 못 잡음 | 시편마다 첫 장 고정물 위치를 기준과 비교 |

### 8. 열린 것
- 기준 샤프트: 어떤 시편을 쓸지, 업체 실측을 같은 날 다시 받을 수 있는지, 두 번째 V블록이 필요한지
- 수동 초점이 끝까지 유지되는지 촬영 전 확인(30분 켜 두기)
- 선행 개발자의 7가지 적용 코드로 같은 표 다시 만들기 (문서 끝 숫자가 V2 보고서와 소수 여섯째 자리까지 같아서 적용 후 결과인지 확인 필요)
- 합격 기준 초안: 평균 찍기 대비, NG 판별, 반복성을 단계로
- 촬영 일정 (목요일 불가)
