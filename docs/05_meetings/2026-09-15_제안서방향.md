## 제안서 방향

- 목표: **파일럿 개발 완료** — 현장 측정 앱(V2)을 현장에서 수행 완료

  1. 물리적으로 잴 수 있나 (NG 이탈 폭이 3σ보다 충분히 큰가)

  4. 업체에 가치가 있나

## 선행 Pilot 발표자료에서 받은 것

- 기능 구현(현재)과 성능 검증(Pilot)을 엄격히 가른다. **검증 전 수치는 성과로 쓰지 않는다**
- 평가 5영역: 정확성 · 판정성능 · 반복성 · 강건성 · 운영성
- 성공기준 숫자는 착수 때 품질담당자와 합의

## 검증 수치에는 통계가 있어야 한다

기존 수치에 신뢰구간을 붙이니 점 하나로 쓰면 과장이 된다.

| 수치 | 점으로 | 95% 신뢰구간 |
|---|---|---|
| 측정 sd (n=7) | 30.1µm | 19.4 ~ 66.3µm |
| NG 검출 3/3 | 100% | 29 ~ 100% |
| 헛경보 0/7 | 0% | 0 ~ 41% |

- %GRR(6σ ÷ 공차 전폭) = 903% → 공차 판정이 범위 밖인 정량 근거
- "검출률 90% 이상"을 주장하려면 NG 29개를 하나도 안 놓쳐야 한다
- 해법: 성공기준을 **통계 규칙**(예: 신뢰구간 상한 ≤ X)으로 쓰고, X는 품질담당자와 합의

## 측정시스템 기록 양식(팀 자료)에서 받은 것

- 보고 필수값: n · Bias · MAE · 최대 절대오차 · s · 6s · %Tolerance · 추적성 · 보정/검증 분리
- 판정 문구 3단(만족 / 조건부 / 유보)
- 보완할 점: "만족" 기준(6s ≤ 2µm)은 지금 대비 약 90배 개선이 필요 / 기준값이 1µm 단위라 MAE 0.5µm는 검증 불가 / 기록표에 이미지 파일명·회차 열 추가 / NG 검출 용도의 네 번째 판정 문구
