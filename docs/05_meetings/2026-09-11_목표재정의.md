# 2026-09-11 팀빌딩 · 목표를 다시 정의하다

## 팀빌딩

자율 프로젝트로 발표했고 3인 팀이 꾸려졌다. 작업 영역은 세 갈래(광학·측정 / 인식·데이터 / 시스템·평가).

## 목표 재정의 (1차)

"±0.010mm 판정 달성"이 아니라 **"비전 측정으로 판정 가능한 공차 경계를 실험으로 확정한다."**
불가능한 목표를 측정 가능한 질문으로 바꿨다. 승부처는 알고리즘보다 지그와 촬영 설계다.

## 추가 자료를 열어보고 방향이 한 번 더 바뀌었다

- 도면: Ø20 +0.03/+0.01 = **20.010~20.030** 확인
- 7/9 촬영 10장 (정상 7 + NG 3), 2992×2992
- 7/9 실측: 정상 7개 20.020~20.022 (폭 2µm) / NG 3개 20.603, 20.492, 20.564 (규격 상한에서 +0.46~+0.57mm)

| | 크기 | 측정 산포 대비 |
|---|---|---|
| 공차 전폭 | 0.46px | 0.44배 → 불가능 |
| 7/9 NG 최소 이탈 | 10.7px | 10.2배 → 지금 광학계로도 가능 |

같은 데이터 안에 되는 것과 안 되는 것이 23배 차이로 같이 있다.
→ 비전의 임무를 **"경계 판정"에서 "공정 이상 조기검출 + 기록 자동화"로** 옮겼다. 게이지와 경쟁이 아니라 분업이다.
→ 산포(σ) 실험은 곁가지가 아니라 판정 문턱(회색지대 = k·σ)을 정하는 부품이 됐다.

## 함정 둘

1. **라벨 누수** — NG 샤프트에 손글씨 "N1"이 있다. 분류 모델이 글씨를 읽고 맞힐 수 있다
2. **전제 불일치** — 선행 제안서는 척에 물린 상태 촬영 전제인데, 실제 사진은 탁자 위에서 찍었다
