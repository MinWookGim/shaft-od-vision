## 결과

| 항목 | 값 | 뜻 |
|---|---|---|
| 처리 규격 | 2992px 축소본, 1px = 34.7µm | 원본 그대로 넣으면 측정이 무너짐 (아래 참고) |
| 시편 안 반복 산포 | 0.02~0.21px = **1~7µm** | 7월(30µm)보다 4배 이상 안정. 촬영은 잘 됐음 |
| 실측 vs 측정 상관 | 전체 13개 **0.47** / 이상치 2개 빼면 **0.96** | 두 시편(S04·S07)이 전체를 끌어내림 |
| 자기정규화 후 상관 | 전체 13개 **0.94** | 아래 설명 |
| N01 제외 12개 상관 | **0.14** | 정상품끼리는 구별 못 함 |
| 촬영 모드 섞을 때 오차 | **+486µm** | 200M으로 캘리브하고 12M을 재면 0.5mm 틀림. 캘리브는 모드별로 |

**왜 정상품끼리 구별이 안 되나**: N01을 뺀 12개의 실측 폭이 20.006~20.040 = 34µm인데, 1픽셀이 34.7µm입니다. 구별해야 할 차이 전체가 1픽셀입니다. 반면 시편을 놓을 때마다 10~15픽셀이 흔들립니다. 신호 1 대 잡음 10입니다.

**N02·N03이 정상으로 나온 이유**: 규격에서 +10µm, −4µm 벗어난 것이라 측정 오차(약 ±20µm)보다 작습니다. 못 잡는 게 당연합니다. N01(+385µm)만 잡힙니다.

## 새로 찾은 방법 — 자기 정규화

측정부 지름을 **같은 부품의 다른 구간(굵은 부분) 지름으로 나눈 비율**을 씁니다. 부품이 카메라에 조금 더 가깝거나 멀게 놓이면 두 구간이 같은 비율로 커지고 작아지므로, 비율은 그대로입니다.

- S04(전체 −2%), S07(전체 +3%)의 배치 오차가 이걸로 사라졌습니다. 상관 0.47 → 0.94
- 반복 정밀도 0.025%
- 새 촬영 없이 얻은 결과라 제안서에 그대로 씁니다

단, 이걸로도 정상품끼리는 못 가릅니다(잔차 ±20µm, 폭 34µm).

## 밤 실험 — 픽셀을 잘게 쪼개면 되나

200M 원본(1px = 8.3µm)으로 다시 재봤습니다. 기본 설정으로는 측정이 무너졌고, 허용 범위를 좁히고 서브픽셀 피팅 창을 넓히니 살아났습니다. 결과:

```
1px 크기      34.7 → 8.3 µm   (4배 잘아짐)
반복 산포     3.8 → 3.5 µm    (같음)
```

**픽셀을 4배 쪼개도 물리 단위 산포가 그대로**입니다. 바닥은 픽셀이 아니라 **엣지 자체의 흐림 폭(광학·조명·폰 후처리)** 이 정합니다. 그래서 "더 가까이 찍기"만으로는 여기서 더 못 내려갑니다.

## 오차의 구조와 순서

```
전체 오차² ≈ 배치 오차² + 엣지 오차²
지금:         ±20µm         3.5µm
```

배치가 6배 큽니다. 엣지를 먼저 날카롭게 해도 전체는 안 바뀝니다. 순서는:

1. **배치 오차부터** — 축 스토퍼 지그, 망원으로 멀리서(거리 민감도 감소), 텔레센트릭이면 더 좋음. 목표 ±20 → 3µm
2. **그 다음 엣지** — 평행광 백라이트, RAW(샤프닝·JPEG 제거), 흑백 센서. 목표 3.5 → 1µm
3. 픽셀은 당장 병목 아님

둘 다 되면 σ 약 3µm, 회색지대 ±9µm. AIAG 합격(σ 0.33µm)은 아니지만 N02급(+10µm)이 경계에 들어옵니다.

## 캘리브레이션 — 3점이 안 되는 이유

서로 0.25mm 이상 벌어진 시편 3개가 필요한데, 멀리 떨어진 건 N01 하나뿐입니다. 어제 7µm 간격의 두 시편으로 2점을 세워봤더니 기울기가 19% 어긋났습니다. 간격이 좁으면 기울기가 잡음으로 정해집니다.
→ 지금은 **N01 + 정상품 평균의 2점**으로 가고, 3점은 정삭 전 소재나 핀게이지를 확보한 뒤로 미루는 것을 제안합니다.

## 다음 촬영 프로토콜 (제안)

```
5배 망원, 측정 구간이 화면 80%    ← 픽셀보다 거리 민감도 때문
V블록 + 축 스토퍼               ← 배치 오차
같은 초점면에 핀게이지 동시 촬영  ← 장마다 자체 캘리브, 모드 오차 소멸
RAW + JPEG 동시 저장             ← 엣지 실험용 (한 부품 고정 10장이면 충분)
고정 10장 + 재장착 20~30장       ← 재현성 산포는 아직 없음
```

재촬영은 업체 일정·거리 때문에 쉽지 않으니 다음 방문 한 번에 위를 다 챙기는 게 좋겠습니다.

## 제안서에 쓸 문장 (초안)

> 본 시스템은 공차 합/불 판정기가 아니라 **공정 이상 검출기**다. 규격에서 약 60µm 이상 벗어난 부품은 검출하고, 30µm 이내는 게이지 판정에 맡기며, 그 사이는 회색지대로 게이지에 회부한다. 검출률·헛경보율의 수치는 NG 표본 확보 후 확정한다.

검출률을 %로 쓰면 안 됩니다. 큰 불량 표본이 4개뿐이라 통계적으로 말할 수 있는 하한이 47%입니다.
