## 1. 같은 사진인데 값이 튄다 -> 원인은 입력 해상도

S01 14장(같은 파일, 해시 일치)을 두 방식으로 쟀다.

| 입력 | 튄 장수 | 정상 장의 반복 흔들림 |
|---|---|---|
| 원본 6008px | **5 / 14** (2·3·4·5·14번이 1342 ~ 1523px, 정상 약 1157px) | 14.3µm (정상 9장) |
| 2992px로 축소 | **0 / 14** | 5.0µm (같은 9장) · 14장 전체 6.5µm |

- 튄 5장을 섞어 캘리브하면 1px 값이 약 9% 어긋난다 (20mm에서 약 1.8mm)
- 카메라·손 떨림 문제가 아니다. 원본에서는 측정기가 엉뚱한 엣지 쌍을 고른다 (D-001)
- **제안: 앱·엔진 입구에서 긴 변 2992px로 줄이는 한 줄을 넣는다**

## 2. 측정 구간 규격 — 말과 코드가 다르다

| | 가로 구간 | 측정선 수 |
|---|---|---|
| 오전 회의 설명 | 양쪽 20% 빼고 가운데 60% | 15 |
| 선행 엔진 코드 (`measurement_engine.py`) | 18% ~ 82% (64%) | 31 |

- 측정부가 평평해서 구간을 조금 옮겨도 정상품은 약 3µm 이하로 변한다. 크지는 않지만 **문서가 하나여야 한다**
- 정할 것: ① 구간 비율 ② 측정선 수 ③ 대표값(중앙값 / 평균) ④ 원통도는 이번 범위에 넣나
- 정한 값은 `docs/04_decisions/D-003` 으로 남기고 코드 상수와 맞춘다

## 3. 캘리브와 검증은 촬영 방식이 달라야 한다

| 단계 | 목적 | 촬영 | 이유 |
|---|---|---|---|
| 캘리브 | 시편별 기준값(px) 확보 | 고정 촬영 평균 가능 | 시편 평균 흔들림 0.7 ~ 1.9µm로 깨끗하다 |
| 검증 | 실제로 쓸 때 오차가 얼마인지 | **다시 놓고 20 ~ 30장** | 오차의 대부분이 놓는 방식에서 온다 |

- 근거: 측정부 값 그대로 쓰면 12개 오차 189µm, 잘못 놓인 2개(S04·S07)를 빼면 32µm
- 고정 촬영 14장은 시편당 "놓은 횟수 1번"이다. 지그 없이 고정 캘리브를 하면 **그 한 번의 배치 오차가 기준값에 박힌다** (S04 −329µm)
- 지금까지 다시 놓고 찍은 데이터는 0건이다
- **멘토 질문 1번 후보**: "캘리브 검증을 고정 촬영으로 해도 되나, 재장착이 들어가야 하나"

## 4. 좌표 라벨링 제안 — 용도를 나눠서 보자

| 용도 | 지금 상태 | 판단 |
|---|---|---|
| 측정 위치 찾기 (긴 축 말고 가공부를 잡기) | 학습된 YOLO가 가공부를 잡는다. 처음 받은 코드가 긴 축을 잡은 원인은 아직 확인 안 함 | 이미 됨. 배경이 지저분하면 흔들린다 (S07 신뢰도 0.25 ~ 0.29, 1장 검출 실패) |
| 합불 판정 (NG / OK 이해시키기) | 정상 12개의 실측 폭 34µm = 약 1px | 사진에 정보가 없다. 라벨을 줘도 모델이 만들어낼 수 없다 |

- 위치를 정밀하게 맞춘 창과 고정 창의 결과 차이 0.06px 이하 (단 고정 촬영이라 위치 차이 자체가 작았다)
- 오히려 값진 정답 데이터는 박스가 아니라 **칼라·끝단 외경 실측값**이다 (5번 체크리스트)

## 5. 다음 촬영 체크리스트

**이 목록은 50 ~ 55µm 검출을 믿을 만하게 만들고 남은 오차의 원인을 가리기 위한 것이다. 공차(±10µm) 판정용이 아니다** — 다 지켜도 엣지 흐림 바닥 3.5 ~ 4µm가 남는다 (6번).

- [ ] 배경이 백라이트로만 채워지게 (공책·자 빼기). 9/16 사진은 윗면이 회색으로 찍혀 순수 실루엣이 아니었다
- [ ] 기준물(핀게이지·게이지블록)을 **샤프트와 같은 평면, 초점 안, 센서와 평행**하게. 지름은 측정부와 비슷하게(20mm 근처), 샤프트와 틈을 두고, 같은 노출로 한 장에. 9/16의 자는 뒤 평면이라 기준으로 못 썼다
- [ ] 측정부가 화면을 더 크게 차지하게 (클로즈업)
- [ ] RAW + JPEG 동시 저장
- [ ] 같은 시편 **다시 놓고 20 ~ 30장** (검증용)
- [ ] 높이·기울기를 고정하는 받침 (S04·S07은 다른 시편보다 70 ~ 130px 높게, 3 ~ 5배 기울게 놓였다)
- [ ] 업체에 **칼라·끝단 외경도 실측** 요청 (남은 오차 13 ~ 21µm의 원인을 가를 수 있다)
- [ ] 한 번 방문에 캘리브용·검증용 두 세트를 다 찍는다

## 6. 제안서 목표 문장

- 지금 확인된 것: 칼라·끝단 두 기준으로 보정하면 오차 sd 약 17µm -> **규격에서 약 50 ~ 55µm 이상 벗어난 부품은 검출**. N01(가공 누락)은 오차의 약 15배로 뚜렷
- 안 되는 것: 공차 ±10µm 판정. 오차 sd가 약 3µm 이하여야 한다 (지금의 1/5 ~ 1/6)
- 파일럿 완료 기준 후보: **"규격에서 약 55µm 이상 벗어난 부품을 놓치지 않고 검출 + 측정 이력 자동 기록"**
- 검출률 %는 쓰지 않는다 (큰 불량 표본 4개뿐)
