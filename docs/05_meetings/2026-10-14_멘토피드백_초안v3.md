# 1차 멘토링 후속 보고

멘토님, 10월 10일 멘토링 감사합니다. 주신 방향과 메일 자료를 적용해 본 결과를 짧게 정리했습니다.

## 요약

- 말씀하신 대로 경계를 사진 위에 그려 보니, **오차는 샤프트 아래 경계의 빛 띠 한 곳에서** 생기고 있었습니다.
- 규칙 보정과 학습으로는 지금 사진의 오차를 공차 안으로 못 줄여서, **촬영 단계에서 아래 빛을 막는 것**을 먼저 하기로 했습니다.
- 보내 주신 증류 이상 탐지는 지름 측정에는 맞지 않았고, **측정 전에 촬영 품질을 거르는 보조 모듈**로 쓸 수 있는지 검토 중입니다.

## 항목별 결과

| 멘토님 방향·자료 | 수행 | 결과와 의견 |
|---|---|---|
| 경계를 이미지로 먼저 확인 | 완료 | 샤프트 위·핀게이지는 깨끗한 경계 하나<br>샤프트 아래만 빛 띠와 계단이 0.7~0.9mm 폭으로 있음<br>가장 도움이 된 조언 |
| 아래 빛 번짐 띠가 원인일 것 | 일부 | 오차가 생기는 곳은 아래 경계로 확인<br>띠가 생기는 이유(조명·반사·렌즈)는 아직 확인 못함 |
| 레퍼런스(핀게이지) 먼저 확인 | 일부 | 반복성은 좋음(같은 시편 10장 편차 3.4µm)<br>핀은 샤프트와 지름·놓인 깊이가 달라 기준으로 쓰기엔 한계<br>다음엔 치수를 아는 샤프트를 기준으로 번갈아 찍을 예정 |
| 패턴 있으면 규칙, 없으면 학습 | 완료 | 약한 패턴 하나(아래 경계 흐림 폭). 보정해도 평균 오차 10.8µm로 공차에 못 미침<br>아래 경계는 사진 안에 정답 경계가 없어 학습 라벨도 못 만듦 |
| 화소·각도가 좋으면 스마트폰도 가능 | 일부 | 해상도를 절반으로 줄여도 오차가 크게 달라지지 않음<br>지금은 화소보다 조명이 먼저로 보이고, 확대 촬영은 다음에 시험 |
| 증류 이상 탐지 논문·코드 | 완료 | 실제 NG 구별 AUC 0.28~0.59로 지름 측정에는 부적합<br>그려 넣은 경계 결함(0.2~0.5mm)은 AUC 0.86~0.97로 잡힘<br>코드를 읽어 보니 품질 검사로 쓰려면 임계값 판정·단일 영상 추론을 따로 만들어야 함 |
| 목적에 맞는 경량 모델 | 완료 | 작은 YOLO로 측정 위치 찾기: 같은 날 사진은 모두 찾음(지름 영향 1~2µm)<br>다른 날·다른 구도 사진은 못 찾음, 촬영 구도 고정이 전제 |

## 다음 계획

- 3차 촬영에서 아래 빛을 가린 사진과 안 가린 사진을 같은 시편으로 번갈아 찍어 비교
- 촬영 직후 아래 경계가 깨끗해졌는지 현장에서 바로 확인하는 점검 도구 준비

## 다음 멘토링에서 여쭙고 싶은 것

1. 실루엣 아래쪽에만 생기는 빛 띠를 없애 보신 경험이나, 원인을 가려내는 방법
2. 배율을 키워 찍는 것과 조명을 먼저 개선하는 것 중 어느 쪽을 먼저 보면 좋을지
3. 이상 탐지를 측정 앞단의 촬영 품질 검사로 쓰는 구성에 대한 의견 (용접 검사에서 정상 반사와 이상을 어떻게 나누셨는지)
