# 1차 멘토링 후속 보고

멘토님, 10월 10일 멘토링 감사합니다. 주신 방향과 메일 자료를 적용해 본 결과를 정리했습니다.
요약 세 가지를 먼저 적고, 아래 1~3절에 각 요약의 근거를 멘토님 방향별로 적었습니다.
팀장은 사진 분석과 실행 시험, 선행 개발자는 측정 엔진과 코드 검토 쪽에서 각각 확인했고, 팀원은 다른 방법으로 같은 사진을 따로 분석해 결과를 맞춰 봤습니다.

## 요약

1. 말씀하신 대로 경계를 사진 위에 그려 보니, 위 경계와 핀은 깨끗했고 **문제는 샤프트 아래 경계(빛 띠와 계단)에 몰려 있었습니다.** 시편을 바꿀 때의 카메라 이동·초점 변화 같은 다른 원인도 섞여 있습니다. (1절)
2. 규칙 보정과 학습으로는 지금 사진의 오차를 공차 안으로 줄이지 못해, **촬영 조건 개선(아래 빛 막기, 확대 촬영)을 먼저 시험**하기로 했습니다. (2절)
3. 보내 주신 증류 이상 탐지는 지름 측정에는 맞지 않았고, **측정 전에 촬영 품질을 거르는 보조 모듈**로 쓸 수 있는지 검토 중입니다. (3절)

## 1. 문제는 아래 경계에 몰려 있다 (요약 1의 근거)

| 멘토님 방향 | 팀장 (사진 분석) | 선행 개발자 (측정 엔진) |
|---|---|---|
| 경계를 이미지로 먼저 확인 | 샤프트 위·핀게이지는 깨끗한 경계 하나<br>샤프트 아래만 빛 띠와 계단이 0.7~0.9mm 폭으로 있음<br>가장 도움이 된 조언: 경계 검출 코드 자체는 문제가 없고, 문제는 사진(아래 경계)에 있다는 것을 확인할 수 있었음 | 측정 위치를 시각화해 확인<br>표면 반사띠가 경계로 잘못 잡히지 않게 전처리 7가지를 정리 |
| 아래 빛 번짐 띠가 원인일 것 | 오차가 생기는 곳은 아래 경계로 좁혀짐<br>띠가 생기는 이유(조명·반사·렌즈)는 아직 확인 못함 | 반사 전처리를 적용해 보니 이번 사진에서는 결과가 대부분 같았음<br>촬영 조건이 바뀔 때를 위한 안전장치로 유지 |
| 레퍼런스(핀게이지) 먼저 확인 | 핀 지름의 반복성은 좋음(같은 핀 10장 편차 3.4µm, 반복성일 뿐 정확도는 아님)<br>핀은 샤프트와 지름·놓인 깊이가 달라 척도 기준으로는 한계<br>치수를 아는 샤프트를 기준으로 번갈아 찍는 방안을 검토 중 | 핀만 따로 측정해 보니 오차가 크지 않아 측정은 됨<br>핀(매끈한 면)과 샤프트(가공면)는 OpenCV가 보는 방식이 다름 |

## 2. 촬영 조건 개선이 먼저 (요약 2의 근거)

| 멘토님 방향 | 팀장 (사진 분석) | 선행 개발자 (측정 엔진) |
|---|---|---|
| 패턴 있으면 규칙, 없으면 학습 | 규칙: 약한 패턴 하나(아래 경계 흐림 폭). 보정하면 평균 오차 15.5 -> 10.8µm지만 공차(±10µm) 안에 못 들어옴<br>학습: 아래 경계는 사진 안에 정답 경계가 없어 라벨을 못 만듦 | 규칙 쪽으로 진행: 측정 위치를 좌표로 고정하고, 조금씩 어긋나는 위치는 주변 기준 영역(Anchor)을 따라가며 보정<br>현업에서는 고정 지그가 위치 잡는 역할을 할 수 있음 |
| 화소·각도가 좋으면 스마트폰도 가능 | 해상도를 절반으로 줄여도 오차가 크게 달라지지 않음<br>지금은 화소보다 아래 경계 모양을 먼저 보는 것이 맞다고 봄 | 지름이 화면에서 지금 약 545px인데, 2000px 이상으로 키워 찍고 백라이트를 보완하면 가능성이 있다고 봄 |

- 의견이 모이는 곳: 같은 조건으로 다시 찍었을 때 같은 결과가 나오는지(반복 재현)를, 바꾸는 조건을 좁혀 가며 확인해야 한다
- 아직 모르는 곳: 아래 빛 막기와 확대 촬영 중 어느 쪽 효과가 큰지. 3차 촬영에서 둘을 나눠 시험하는 방안을 검토 중이고, 아래 질문 2로 여쭙니다
- 팀원의 독립 확인: 경계 위치를 찾는 다른 방법 3가지(밝기가 반쯤 바뀌는 곳, 밝기 곡선 맞추기, 밝기 변화의 무게중심)로 따로 분석함. 방법끼리의 차이보다 같은 시편을 다시 찍을 때의 흔들림(3\~5µm)이 더 컸고, 측정 없이 정상 시편 평균값을 부르는 것보다 나은 방법이 없었음. 병목은 촬영 환경이라는 같은 결론

## 3. 증류 이상 탐지는 측정 앞 품질 검사로 (요약 3의 근거)

| 메일 자료·제안 | 팀장 (실행 시험) | 선행 개발자 (코드 검토) |
|---|---|---|
| 증류 이상 탐지 논문·코드 | 저희 사진에 실제로 돌려 봄<br>실제 NG(실측이 규격 하한보다 작은 시편 2개, 정상보다 17\~26µm 작음) 구별 AUC 0.28\~0.59로 지름 측정에는 부적합(NG가 2개뿐이라 숫자는 흔들림)<br>위 경계에 그려 넣은 결함은 0.5mm부터 대체로 잡힘(AUC 0.79\~1.00), 0.2mm는 모양에 따라 0.65\~0.92<br>결함이 없어도 히트맵이 아래 경계에서 높게 뜸 | 코드 5개 전체를 읽고 검토<br>외경을 직접 계산하는 구조가 아니라 특징 차이로 이상 점수를 내는 구조<br>측정 앞단의 촬영 품질 검사로 쓸 가능성이 있으나, 임계값 판정·단일 영상 추론·라벨 처리를 보완해야 함 |
| 목적에 맞는 경량 모델 | 작은 YOLO로 측정 위치 찾기: 같은 날 사진은 모두 찾음(지름 영향 중앙값 1~2µm, 단 핀이 옮겨진 20장은 크게 어긋남)<br>다른 날·다른 구도 사진은 못 찾음, 촬영 구도 고정이 전제 | 위치를 찾는 과정이 측정에 쓰는 원본 좌표를 바꾸지 않게 분리해야 함 |

- 품질 검사로 쓸 때의 원칙(팀 공통): 흐림·포화·위치 같은 해석 가능한 규칙을 먼저 만들고 이상 탐지는 추가 효과를 비교한다. 촬영 품질과 제품 치수 판정은 분리한다(촬영이 괜찮은 치수 불량은 측정 단계로 보내야 한다)
- 한계: 아래 경계 빛 띠는 지금 모든 사진에 있어 정상으로 학습된다. 이 문제는 품질 검사가 아니라 촬영 개선이 맡아야 한다

## 4. 다음 계획

- 3차 촬영: 같은 시편을 아래 빛을 가린 것과 안 가린 것, 지금 배율과 확대 배율로 나눠 찍어 비교 (세부 시나리오는 팀에서 협의 중)
- 거리별 시험: 10·20·30·40cm에서 찍어 지름이 몇 px로 잡히는지와 어느 렌즈로 찍혔는지 기록
- 시편마다 샤프트 높이를 기록하고, 시편을 바꿀 때마다 첫 장에서 기준 위치를 다시 점검
- 기준물: 규격 상한·중간·하한 치수의 기준물로 기준선을 만드는 방안 검토 (현장 고정 구조물 여부 확인 필요)
- 촬영 직후 아래 경계가 깨끗해졌는지 현장에서 바로 확인하는 점검 도구 준비
- 개선 여부를 판단할 내부 기준(측정 항목과 기준값)을 촬영 전에 정함

## 5. 다음 멘토링에서 여쭙고 싶은 것

1. 실루엣 아래쪽에만 생기는 빛 띠를 없애 보신 경험이나, 원인을 가려내는 방법
2. 배율을 키워 찍는 것과 조명을 먼저 개선하는 것 중 어느 쪽을 먼저 보면 좋을지, 거리별 시험에서 함께 봐야 할 것
3. 이상 탐지를 측정 앞단의 촬영 품질 검사로 쓰는 구성에 대한 의견, 그리고 용접 비전 검사를 양산에 넣으실 때 어떤 기준으로 판정하셨는지
