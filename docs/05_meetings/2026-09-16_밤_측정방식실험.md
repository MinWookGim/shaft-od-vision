# 2026-09-16 밤 ~ 09-17 새벽 — 새 촬영 없이 짜낼 수 있는 것

재촬영은 업체 약속·거리 때문에 어렵다. 어제 161장으로 할 수 있는 최선을 찾았다. 숫자는 `02_facts.md`.

## 1. 측정 방식 네 가지 비교

| 방식 | 전체 13개 r | N01 제외 12개 r |
|---|---|---|
| A 장별 YOLO 박스 | 0.471 | −0.065 |
| B 시편별 고정 박스 | 0.470 | −0.065 |
| **C 자기 정규화 (측정부 ÷ 기준부)** | **0.939** | 0.136 |
| D 허용범위 박스 기준 | A와 차이 0.12px 이하 | − |

- B = A → 한 시편 안에서 박스는 이미 안 흔들린다
- **C가 S04·S07을 되돌렸다.** 한 사진 안의 굵은 구간으로 나누면 부품이 조금 가깝거나 멀게 놓여 생긴 배율 차이가 상쇄된다
- 그러나 N01을 빼면 C도 0.136. 정상품끼리는 여전히 구별 못 한다 — 12개의 폭 34µm가 1픽셀이고, 배치 잡음이 10~15픽셀이다
- D(09-12에 찾은 박스 기준)는 이 사진들에서는 할 일이 없었다. 박스가 이미 잘 잡혀 있어서다

## 2. 픽셀을 잘게 쪼개면 되나 — 원본 해상도 실험

200M 2× 세트 10장(1px = 8.3µm)을 원본 그대로 쟀다.

1. 기본 설정: **붕괴** (sd 338px). 허용 범위가 원본에서 넓어져 가짜 엣지 쌍이 섞인다
2. 허용 범위를 박스 높이의 0.762~0.778로 좁힘: 가짜 쌍 사라짐. 그런데 sd 5~7µm에서 멈추고 값의 60~70%가 정수
3. 원인: 서브픽셀 보정이 봉우리 좌우 **3점** 포물선이다. 원본은 엣지가 4배 넓어 봉우리가 평평 → 보정 포기 → 정수
4. 창을 ±12px 무게중심으로 넓힘: 정수 0%, **sd 3.47µm**

```
1px 크기   34.7 → 8.3 µm   (4배 잘아짐)
반복 산포   3.8 → 3.5 µm    (같음)
```

**픽셀을 4배 쪼개도 물리 단위 산포가 같다.** 바닥은 픽셀이 아니라 엣지 자체의 흐림 폭(광학·조명·폰 후처리)이다.
주의: 창 크기에 따라 평균이 8px(약 65µm) 움직인다. 창을 바꾸면 캘리브를 다시 해야 한다.

## 결론 — 오차의 구조와 순서

```
전체 오차² ≈ 배치 오차² + 엣지 오차²
지금:         ±20µm         3.5µm
```

1. **배치 오차부터** — 축 스토퍼 지그, 망원으로 멀리서(거리 민감도 감소), 텔레센트릭
2. **그 다음 엣지** — 평행광 백라이트, RAW(폰 후처리 제거), 흑백 센서
3. 픽셀은 당장 병목이 아니다
