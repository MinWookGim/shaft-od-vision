# D-001 측정 처리 규격은 2992px 축소본으로 고정한다

- 날짜: 2026-09-16
- 결정: 촬영 원본 해상도와 무관하게, 측정·학습은 **가로 2992px로 축소한 이미지**에서 한다
- 근거: 원본(6008·12240)을 기본 파라미터로 넣으면 엣지 쌍 선택이 널뛰어 측정이 무너진다. 2992에서는 10/10 안정. 원본을 살리려면 파라미터를 스케일에 맞춰 다시 잡아야 하는데(허용 범위 좁힘 + 넓은 창 서브픽셀), 그렇게 해도 산포가 2992와 같았다 (`02_facts.md`)
- 영향: 파이프라인 입구에 리사이즈 단계 고정. YOLO 학습도 같은 규격
- 되돌리는 조건: 엣지 선명도(조명·RAW)가 개선돼 원본에서 산포가 실제로 줄어들 때
