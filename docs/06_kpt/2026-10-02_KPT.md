# KPT 2주차 — 팀장 추가분 (팀 노션 KPT에 없는 것만)

## 지난 주 Try 점검

- 복수 기준값 캘리브 + 별도 검증 -> **했다**(NO1~3 캘리브, NO4~6 검증)
- measure()에 placement_error 판정 로직 -> **코드에는 아직 없다.** 대신 현장에서 사진마다 핀게이지 px로 거치 이상을 보는 확인 도구를 만들었다
- 축 높이 오프셋 분석 스크립트 -> 촬영 계획에만 넣었다(블록 F). 스크립트는 아직
- 핀게이지 등 장비 주문 -> **했다.** 핀게이지 Ø10 × 5개

## ✅ Keep

🔷 **현장 전에 집에서 미리 찍어 보기**
- 2차 촬영과 같은 조건(40cm·200MP·핀게이지)으로 집에서 먼저 찍어, 차광·핀 위치·배치 흔들림 문제를 현장 가기 전에 찾았다.
- 현장 하루를 시행착오가 아니라 확인 실험에 쓸 수 있게 됐다.

## ⚠️ Problem

🔶 **합격 기준을 촬영 전날까지 정하지 못함** (-> 팀 Try "평가 항목과 합격 기준 사전 정의")
- 검증 통과 기준(µm)·파일명 규칙·최소 완료선이 10-01 회의에서도 정해지지 않았다.
- 결정 항목마다 마감이 없어서, 급한 촬영 조건 논의에 밀렸다.

🔶 **기준값·시편의 출처 확인 부족**
- 1차 실측값을 어떤 계측기로, 언제 교정받은 것으로 쟀는지 기록하지 않았다. 측정 결과를 인정받으려면 기준값이 교정된 계측기에서 나왔다는 근거가 필요하다.
- NG품 10개를 업체가 만들 수 없다는 것을 촬영 전날 알았다. 업체 생산 사정을 먼저 확인하지 않고 수량부터 요청했다.
