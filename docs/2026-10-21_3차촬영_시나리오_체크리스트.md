# 10-21 3차 현장 촬영 시나리오·체크리스트 (13시, 원전기계)

기준 = 선행 개발자 「3차 측정 촬영 시나리오/체크시트」(10-20). 그 순서(공통 세팅 -> 300/400mm 거리 비교 -> 선정 거리에서 본시험)를 따르되, 맨 앞에 아크릴 유무 시험 촬영을 넣었다(10-21 결정). 나머지는, 그 사이에 **[추가]** 표시한 것만 넣었다.
선행 개발자 체크시트(시트 A\~D, 회차별 Edge 확인표)는 따로 인쇄해 쓰고, 이 문서는 전체 순서표로 쓴다.
(10-19 시나리오, 10-20 체크리스트 두 문서를 이 문서 하나로 합쳤다. 이전 내용은 git 기록에 있다.)

## 부록 C. 약점

- 2부가 본시험보다 늦게 찍혀서, 둘의 차이에는 "다시 놓은 효과"와 "시간 효과"가 섞인다. 시간 효과는 움직이지 않는 핀의 px로만 본다. 핀 px가 처음과 끝에 같으면 시간 효과가 작다고 보고, 다르면 재장착 흔들림은 부풀려진 값으로 읽는다.
- CAL 세 개의 실측 폭이 20µm로 사진 1px(약 37µm)보다 작다. (가)의 회귀 기울기는 이번에도 불안정할 수 있다. 촬영으로 풀 수 없는 한계라서 (나)를 나란히 둔다.
- 0부 결과와 상관없이 본시험·2부는 암막천 있음으로 찍으므로, 이번 본시험은 "조건 동결 후 본시험"이 아니라 예비 확인이다.
