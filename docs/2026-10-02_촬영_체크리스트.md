# 10-02 현장 촬영 체크리스트 (순서대로)

근거·이유는 [`2026-10-02_2차촬영_계획서.md`](./2026-10-02_2차촬영_계획서.md). 이 문서는 현장에서 위에서부터 체크만 하면 되도록 순서만 정리했다.

**최소 완료선 = 4번(블록 C)까지.** 시간이 남으면 5번부터 순서대로.

---

## 0. 출발 전

- [ ] 폰 저장 공간 **5GB 이상**(약 250장 × 10MB ≈ 2.5GB + 여유), 배터리 100%, 보조배터리
- [ ] 폰 카메라 **200MP 모드**, **1배 메인 렌즈** 확인
- [ ] 백라이트(A4) + 전원
- [ ] **검은 천** 1\~2장 또는 검은 폼보드 + 집게·테이프 (흰 판 금지)
- [ ] 핀게이지 Ø10 × 5개, **핀 받침**(평평한 금속 블록)
- [ ] V-block, 직각자, 줄자, 마스킹 테이프
- [ ] 거치대(삼각대), **리모컨 또는 타이머**
- [ ] 노트북(즉석 확인용), 기록지 인쇄
- [ ] 3시 회의 결정 반영: 검증 통과 기준(µm), 파일명 규칙, 최소 완료선

## 1. 도착 — 시편·실측

- [ ] 시편 받기·라벨 확인: 상·중·하 **2세트**(1세트 캘리브, 2세트 검증), 측정 4개, 불량 약 10개(종류 기록)
- [ ] 계측기로 재는 과정 관찰: **측정 위치(축 방향 어디), 횟수**
- [ ] 실측값 기록 (가능하면 **칼라·끝단 지름도**)
- [ ] **핀 5개 실측**(가운데 부분, 끝 모따기 제외)
- [ ] 장소 확인: 창문·천장 조명 위치 → 백라이트와 차광 방향 정하기
- [ ] 하이트 게이지·**버니어 캘리퍼스** 빌릴 수 있는지 확인

## 2. 세팅 (선행 개발자 시나리오 + 계획서 3.5절)

- [ ] 평평한 기준면(정반) 위에 모두 배치
- [ ] **백라이트 세우기**: 광축에 직각, 중심 높이 = 샤프트 축 높이(H)
- [ ] **V-block에 샤프트**: 측정부가 V-block **밖으로** 나와 있게(아래 경계가 백라이트 앞)
- [ ] 샤프트 축 → 백라이트 **약 100mm**
- [ ] **직각자를 V-block 앞면에** 붙여 기준선
- [ ] **핀은 세워서** 받침 위에: 핀 앞면을 직각자에서 **W/2 − 5mm 뒤**(캘리퍼스). V-block 폭 W = ____mm
- [ ] 핀과 측정부가 **화면 가운데 1/3** 안, 둘 다 백라이트 앞
- [ ] 폰: 렌즈 중심 높이 = H(하이트 게이지), 광축이 샤프트 축과 직각(직각자)
- [ ] 거리: 렌즈 앞면 → 샤프트 앞 표면 **390mm**(축까지 400mm). **250mm 이하 금지**
- [ ] **차광 설치**: 카메라 쪽만 열고 위·양옆을 검은 천으로
- [ ] 측정부를 길게 눌러 **초점·노출 잠금(AF/AE Lock)**
- [ ] 리모컨·타이머 켜기. 이후 **폰 만지지 않기**
- [ ] **시작 기록**: 폰 기종·앱, 해상도, 백라이트 밝기, 높이값(렌즈·샤프트·핀), 거리 실측, W

## 3. 블록 A — 조건 확인 촬영 (본 촬영 전, 약 8장)

한 단계씩 찍고 확인한다. **통과 못 하면 오른쪽 조치 후 그 단계부터 다시.**

| 단계 | 찍을 것 | 확인할 것 (통과 기준) | 통과 못 하면 |
|---|---|---|---|
| A1 | **백라이트만** 1장 (샤프트·핀 없이) | 화면 안 백라이트가 고르게 밝고, 하얗게 날아간(포화) 부분이 없다 | 백라이트 밝기 한 단계 낮추기 → 다시 A1 |
| A2 | **샤프트 + 핀, 차광 없이** 1장 / **차광 후** 1장 | 차광 후 샤프트가 검은 실루엣, 표면 반사 줄이 줄어든다 | 차광 틈 막기(위·옆), 흰 물체 치우기 |
| A3 | 차광 상태 1장을 **확대해서 보기** | 측정부와 핀이 **화면 가운데 1/3**, 경계가 선명, 경계 뒤가 전부 백라이트(V-block·받침이 안 가림), 샤프트 지름 **약 400px 이상** | 위치 조정 / 측정부 눌러 초점 다시 잠금 / 거리 결정(팀) |
| A4 | 폰 건드리지 않고 **3장 연속**(타이머·리모컨) | 3장 사이 **핀 px 차이 0.1% 이하**(거치 안정) | 거치대 조이기, 바닥 진동·사람 동선 확인 → 다시 A4 |
| A5 | **"중" 시편**으로 바꿔 1장 | 핀 px로 환산한 지름이 실측과 **0.1% 이내**(핀 깊이 일치) | 0.1% 다를 때마다 핀을 약 0.4mm 앞뒤로 → 다시 A5 |

- [ ] A1 통과   - [ ] A2 통과   - [ ] A3 통과   - [ ] A4 통과   - [ ] A5 통과
- [ ] 핀 px 기준값 기록: ______px (이후 블록에서 이 값과 비교)
- [ ] 화면 가로 시야 확인: 줄자 눈금이 보이게 1장 → 화면 가로 ____mm

**확인 도구 주의**: A4·A5와 멈출 신호는 노트북에서 핀 px를 바로 재야 한다. 현장용 확인 스크립트가 아직 없으니 출발 전에 준비할 것(계획서 4절 A).

---

### 멈출 신호
- 같은 조건인데 **핀 px가 0.1% 넘게 바뀜** → 폰·거치대·렌즈 전환 점검 후 재개
- YOLO가 샤프트를 못 찾거나 경계가 번짐 → 초점·노출·차광 재확인
- 실측을 아직 못 받았는데 시편을 돌려줘야 함 → 실측부터

### 하지 않을 것
- 블록 중간에 줌·해상도·모드 바꾸기, 폰 손으로 만지기, 백라이트 밝기 바꾸기
- 흰 판으로 가리기, 핀을 V-block에 눕혀 얹기
- 원본 사진 덮어쓰기·편집
