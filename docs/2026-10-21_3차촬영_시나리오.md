# 3차 현장 촬영 시나리오 (2026-10-21 13시, 원전기계)

기준 문서: 선행 개발자 「파일럿 검증을 위한 물리적 조건 안정화 방안」(10-19)과 업체 예약 내용(CAL 3, VAL 3, RAN 4, NG 2).
**예약한 촬영(1부)은 순서와 장수를 그대로 둔다.** 이 문서는 그 뒤에 붙는 추가 촬영(2부)과, 그 앞에 하는 차광 비교(0부)를 더한 것이다.
현장에서 위에서부터 체크하는 순서는 [`2026-10-21_3차촬영_체크리스트.md`](./2026-10-21_3차촬영_체크리스트.md).

## 0. 이번 촬영으로 답할 질문

| # | 질문 | 어느 블록 | 안정화 방안 문서와의 대응 |
|---|---|---|---|
| Q1 | 바닥 반사를 가리면 아래 경계 계단(2\~3단)이 사라지나 | 0부 | 5절 차광 전후 비교 |
| Q2 | 같은 시편을 빼고 다시 놓으면 값이 얼마나 흔들리나 | 2부 | Gate 2 재장착 (3회 장착 x 5장) |
| Q3 | 촬영하는 동안 배율이 시간 따라 변하나 | 전 블록의 핀 px (핀은 끝까지 안 움직임) | Gate 1 핀 안정성, Gate 5 관리 시편 확인 |

Q4가 이번 촬영의 최종 질문이다. 10-08 데이터에서는 어떤 측정 방법도 측정 없이 정상 평균값을 부르는 것(정상 시편 10개 LOO MAE 5.8µm)을 이기지 못했다(10-18 멘토링 요약). 이번 촬영의 기준선 값은 4절 정의대로 이번 실측으로 새로 계산한다. 5.8µm를 그대로 통과선으로 쓰지 않는다.

| 항목 | 내용 |

| 백라이트 | 박스 뒷면 안쪽에 벨크로로 고정. 검정 종이로 샤프트·핀 뒤만 남기고 가림. 밝기는 가장 어두운 단계부터 올려 포화 없는 단계로 고정 |

| 측정면 | 샤프트 측정면은 도색·테이프 금지. 검정 마스킹테이프는 지그·주변 금속 반사에만 |

**바꾸지 않는 것**: 한 번 정한 백라이트 밝기, 폰 위치, 거리, 줌, 초점·노출 잠금. 바꿔야 하면 그 시점부터 새 세션으로 기록한다(안정화 방안 9절).

## 2. 촬영 구성

### 0부. 차광 비교 (약 15분, 30장, 1부 다음 순위)

- 시편: **CAL 20.020** 한 개를 놓고 끝까지 건드리지 않는다.
- 바꾸는 것은 **바닥 암막천 하나만**. 박스·백라이트·폰은 그대로.
  - 이유: 백라이트가 박스에 붙어 있어서 박스를 들면 백라이트 위치도 같이 바뀐다. 박스를 빼는 비교는 "차광 유무만 바꾼다"는 조건(안정화 방안 5절)을 지킬 수 없다.
- 넣고 빼는 방법: 암막천을 검정 종이(300g)에 붙여 얇은 판으로 만들고, 박스 앞 촬영 창 아래로 밀어 넣고 뺀다. 시편·박스·폰에 닿았으면 기록한다.
- 순서: **암막천 없음 10장 -> 있음 10장 -> 없음 10장** (안정화 방안의 전 -> 후 -> 전). 시작 전에 암막천을 빼 두고, 끝나면 다시 넣고 1부로 간다.
- 첫 단계 전과 암막천을 넣은 뒤 세팅 사진을 남긴다(안정화 방안 5절).
- 0부 결과와 상관없이 1부·2부는 암막천 있음으로 찍는다. 그래서 1부·2부는 "조건 동결 후 본시험"이 아니라 예비 확인이다.
- 볼 것: 아래 경계 계단 폭(10-08 기준 20\~25px), 위·아래 경계 각각의 세로줄별 흔들림, 핀 px.

### 1부. 예약 촬영 (선행 개발자 계획 그대로, 120장)

- 12개 시편을 **선행 개발자가 정한 순서대로**, 한 번 놓고 10장씩.
- 1부의 장착을 **1회차 장착**으로 기록한다. 0부에서 놓여 있던 CAL 20.020도 1부 차례가 되면 들어냈다가 다시 놓고 찍는다.

| 구분 | 시편 | 장수 |
|---|---|---|
| CAL | 20.010 / 20.020 / 20.030 | 3 x 10 |
| VAL | 20.010 / 20.020 / 20.030 | 3 x 10 |
| RAN | 4개 | 4 x 10 |
| NG | 2개 | 2 x 10 |

### 2부. 추가 촬영 = 재장착 (약 60분, 130장)

- 12개 시편을 **두 번 더 놓고, 놓을 때마다 5장**. 1부와 합치면 시편마다 3회 장착이 된다(안정화 방안 Gate 2의 3회 x 5장과 같은 구성. 1회차만 10장).
- 2부의 **맨 처음과 맨 끝에 CAL 20.020 5장씩**(관리 시편 확인용, 장착 횟수에 안 셈). 이 두 번도 각각 새로 놓은 것이라 재장착 흔들림이 섞인다. 시간 변화는 핀 px로 보고, CAL 20.020은 "큰 이상이 없는지" 확인용으로만 쓴다.
- 순서는 1부와 다르게 섞으면 시간 효과와 시편 차이를 가르기 좋다. 현장에서 어렵다면 1부와 같은 순서로 해도 된다.

```
2부 진행
CAL 20.020 x5 (시간 확인 1)
-> 12개 시편 2회차 장착 x5
-> 12개 시편 3회차 장착 x5
CAL 20.020 x5 (시간 확인 2)
```

**합계: 0부 30 + 1부 120 + 2부 130 = 280장** (조건 확인 촬영 약 5장 별도).

**우선순위: 1부 > 0부 > 2부.** 세팅이 늦어지면 0부를 1부 뒤로 미룬다. 2부에서 시간이 모자라면 RAN부터 3회차 장착을 빼고(빠진 시편 기록), **끝 CAL 20.020 5장은 반드시 찍는다.** CAL·VAL·NG는 3회 장착을 지킨다.

## 3. 실측 (업체 요청)

| 항목 | 내용 |
|---|---|
| 측정 위치 | 사진의 측정 구간(길이의 18\~82%)과 같은 위치를 업체 계측기로. 축 방향 위치와 회전 방향 기록(안정화 방안 3절 "기준값과 ROI") |
| 반복 | 같은 위치 **3회**. 평균과 범위를 기록 (기준값 자체의 흔들림) |
| 칼라·끝단 | 가능하면 같은 샤프트의 칼라·끝단 지름도 실측. 업체에 다른 핀게이지가 없어서, 이것이 환산 비율(1px당 µm)을 Ø10 핀 말고 다른 지름으로 확인할 유일한 방법이다 |
| 계측기 | 종류·모델, 교정 성적서 날짜(사진) |

칼라·끝단 실측이 안 되면 "환산 비율은 핀(Ø10) 한 종류로만 정했고 다른 지름에서는 확인하지 못했다"를 결과의 한계로 적는다.

## 4. 분석 규칙 (촬영 전에 고정)

결과를 보고 규칙을 바꾸지 않았다는 근거를 남기려고, 이 문서를 푸시한 날짜(10-19)로 고정한다. 바꿀 때는 바꾼 이유와 날짜를 덧붙이고 원래 규칙은 지우지 않는다.

| 항목 | 규칙 |
|---|---|
| 측정 방법 | (가) 선행 개발자 V3 방식: CAL 3점 회귀로 mm 환산. 이것을 통과선으로 판정한다 |
| 진단 비교 | (나) 핀 비율 방식: 샤프트 px / 핀 px x 10, 오프셋만 CAL 평균으로 맞춤. 안정화 방안 4절대로 **진단용**으로 같은 사진에 나란히 적는다. 측정 방법으로 쓸지는 결과 보고 팀이 따로 정한다 |
| CAL에 쓰는 사진 | 1부 CAL 3개 x 10장만. 2부 CAL 사진은 회귀에 안 넣는다 |
| 시편 대표값 | 장착마다 사진 평균을 내고, 그 장착 평균들의 평균 (10장 장착과 5장 장착이 같은 무게) |
| 기준선 | 측정 없이 CAL 3개 실측 평균을 부르는 값. 이번 실측으로 계산해 모든 결과표에 같이 적는다 |
| 평가 대상 | VAL 3 + RAN 4 (CAL에 안 쓴 시편). RAN의 정답은 업체 실측값 |
| NG 2 | 시편 대표값이 규격 하한(20.010) 아래로 나오는지. 사진 한 장씩의 OK·NG 수도 같이 |
| 지표 | 시편별 오차(대표값 - 실측 평균), 전체 MAE·최대 오차. 같은 장착 안 sd와 장착 간 sd를 나눠서 |
| 통과선 (제안값) | 1차 관문: VAL+RAN MAE **8µm 이하이면서 기준선보다 작음**. 목표: **3µm** |
| 0부 판정 | 암막천 있음에서 아래 경계 계단 폭이 없음보다 줄고, 두 번의 "없음"끼리는 비슷하면 바닥 반사 효과로 본다 |

- 통과선 숫자는 팀 합의 전 제안값이다. 안정화 방안 8절이 "본시험 전에 수치로 확정"하자고 했으므로, 10-21 전에 팀에서 정하고 여기에 덧붙인다.

## 5. 기록할 것

- 사진마다: 파일명, 시편, 블록(0부·1부·2부), 장착 회차, 암막천 유무, 촬영 시각
- 블록마다: 첫 장의 핀 px (USB로 꺼내 노트북에서 확인)
- 세션 시작·끝: 폰 기종·앱·해상도, 백라이트 밝기 단계, 렌즈-샤프트 거리, 세팅 전체 사진과 측정부 확대 사진

## 약점

- 2부가 1부보다 늦게 찍혀서, 1부와 2부의 차이에는 "다시 놓은 효과"와 "시간 효과"가 섞인다. 시간 효과는 움직이지 않는 핀의 px로만 볼 수 있다. 핀 px가 처음과 끝에 같으면 시간 효과가 작다고 보고, 다르면 재장착 흔들림은 부풀려진 값으로 읽는다.
- CAL 세 개의 실측 폭이 20µm로, 사진 1px(약 37µm)보다 작다. (가)의 회귀 기울기는 이번에도 불안정할 수 있다. 이것은 촬영으로 풀 수 없는 한계라서 (나)를 나란히 두는 것이다.
