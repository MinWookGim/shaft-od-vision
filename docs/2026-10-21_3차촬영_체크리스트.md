# 10-21 현장 촬영 체크리스트 (순서대로)

근거·이유는 [`2026-10-21_3차촬영_시나리오.md`](./2026-10-21_3차촬영_시나리오.md). 현장에서 위에서부터 체크만 하면 되도록 순서만 정리했다.

**우선순위 = 1부(예약 촬영) > 0부(차광 비교) > 2부(재장착).** 세팅이 늦어지면 0부를 1부 뒤로 미룬다.

---

## 0. 출발 전 (10-20까지)

- [ ] 차광 박스: 안쪽 스웨이드 시트 부착, 백라이트 벨크로 자리, 전원선 구멍 + 덮을 암막천
- [ ] 박스 앞면(폰 쪽) **촬영 창** 뚫기. 창 아래로 바닥 판을 밀어 넣을 틈 확인
- [ ] 백라이트 가림용 검정 종이(샤프트·핀 뒤만 열리게 미리 재단)
- [ ] 바닥용 암막천을 검정 종이에 붙여 **밀어 넣는 판**으로(지그 사이 크기). 0부에서 넣고 뺀다
- [ ] 스마트폰 + 미니 바이스(흡착) + 꺾쇠, 리모컨, 보조배터리
- [ ] 폰 촬영 모드 **10-08과 같게**(2억 화소 자동, 1.0x)
- [ ] 폰 저장 공간 **5GB 이상**(10-08 사진 장당 약 8.5MB x 약 290장 = 약 2.5GB + 여유), 배터리 100%
- [ ] 핀게이지 Ø10, 핀 받침·스페이서
- [ ] 검정 마스킹테이프, 재단가위, 커터, 쇠자, 줄자, 가는 펜
- [ ] 노트북(핀 px 즉석 확인 스크립트), 윈도우 노트북 "휴대폰과 연결" + Tailscale 확인, 저장한 사진이 원본(16320 x 7532, 약 8.5MB)인지 미리 확인, 기록지 인쇄(아래 7절)
- [ ] 1부 시편 순서를 선행 개발자에게 받아 5절 표에 채우기
- [ ] 장갑
- [ ] 팀에서 통과선 숫자 확정(시나리오 4절, 제안값 8µm / 3µm)
- [ ] 업체에 미리 문의: 같은 위치 3회 실측, 칼라·끝단 실측 가능 여부

## 1. 도착 — 시편·실측

- [ ] 시편 12개 라벨 확인: CAL 3(20.010 / 20.020 / 20.030), VAL 3(같은 세 값), RAN 4, NG 2
- [ ] 실측 위치(축 방향 거리)·회전 방향 기록. 사진 측정 구간(길이 18\~82%) 안인지 확인
- [ ] 같은 위치 **3회** 실측값 기록
- [ ] (가능하면) 칼라·끝단 지름 실측
- [ ] 계측기 종류·모델, 교정 성적서 사진

## 2. 세팅

- [ ] 정반 위에 V블록·샤프트·핀 배치. 측정부가 V블록 밖, 경계 뒤가 전부 백라이트
- [ ] 핀: 샤프트와 깊이 맞추고 고정. 이후 촬영 끝까지 건드리지 않기
- [ ] 바닥 판 넣는 자리 확인(지그 사이 샤프트 밑). 0부 시작 때는 **빼 둔다**
- [ ] 지그·주변 금속의 반짝이는 곳에 검정 마스킹테이프 (**샤프트 측정면에는 금지**)
- [ ] 박스 덮기. 백라이트 검정 종이 위치 확인(샤프트·핀 뒤만 밝게)
- [ ] 전원선 구멍 암막천으로 덮기, 이음새 빛샘 테이프
- [ ] 폰: 정반에 바이스로 고정, 렌즈 1.0x. 샤프트 축과 직각, 측정부·핀이 화면 가운데
- [ ] 거리 실측 기록: 렌즈 -> 샤프트 앞면 ____mm
- [ ] 노트북 "휴대폰과 연결" 켜고 사진 탭이 보이는지 확인(초점 잠그기 전에). 이후 폰은 카메라 앱에서 나가지 않는다

## 3. 조건 확인 촬영

| 단계 | 찍을 것 | 통과 기준 | 안 되면 |
|---|---|---|---|
| C1 | 백라이트만 1장 | 포화(하얗게 날아간) 부분 없음 | 밝기 한 단계 낮추기 |
| C2 | 샤프트 + 핀 1장, 확대해서 보기 | 위·아래 경계 선명, 경계 뒤가 백라이트, 지그가 안 가림 | 위치·종이 조정 |
| C3 | 초점·노출 잠금(측정부 길게 누름) | 잠금 표시 확인 | |
| C4 | 폰 안 건드리고 3장 연속, 노트북으로 받아 확인 | 3장 사이 핀 px 차이 0.1% 이하 | 바이스·흡착 다시 고정 -> C3부터. 3번 해도 안 되면 값 기록하고 진행 |
