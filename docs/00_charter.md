# 00. 팀 차터

팀 3인 + 밖에 희연님(선행 개발자) + 업체(원전기계). 5자 관계다. 겹침은 숨기지 않고 먼저 밝힌다.

## 작업 영역 (3트랙)

| 트랙 | 내용 |
|---|---|
| 1 광학·측정 | 촬영 리그, 조명, 지그, 캘리브레이션 |
| 2 인식·데이터 | 데이터셋·라벨링, 모델 재학습, 조건별 비교 |
| 3 시스템·평가 | 파이프라인, 실험 설계, 통계, 보고서 |

담당은 고정하지 않고 그때그때 나눈다.

## 정해진 것

- 진행 순서: **캘리브레이션 -> 검증 -> 기준값 확정 -> 그 다음 학습** (09-16 희연님과 합의)
- 제안서 범위: **파일럿 완성까지.** 현업 적용은 쓰지 않는다
- 공개 범위: 외부(발표·공개 저장소)에는 대표 이미지만. 실측값·업체명·원본 사진은 내부 한정
- 사진 원본은 저장소에 넣지 않는다 (용량). 별도 공유

## 정할 것

- [ ] 산출물 귀속 (팀 / 희연님 선행 작업 / 업체 자료의 경계)
- [ ] 파일럿 완료 기준 — "무엇이 되면 끝인지". 후보: 60µm 이상 이상품을 회색지대 없이 검출 + 기록 자동화
