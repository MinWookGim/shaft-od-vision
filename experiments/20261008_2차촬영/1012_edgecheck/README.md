# 10-12 멘토 액션 아이템 2개: 경계 눈으로 확인 + 오차 패턴 확인

10-10 멘토링 후속 조치. 데이터는 10-08 130장(`1008_methods/_out/cache.npz`, 경계 근처만 잘라둔 것).
`overlay.py` -> 그림 2장, `pattern.py` -> 표. 둘 다 1분 안에 끝남.

## 1. 경계를 제대로 잡나 (멘토가 말한 "그라운드 트루스" 확인)

그림: `_out/edge_overlay_13.png`(13묶음 전부, 묶음마다 5번째 사진), `_out/edge_overlay_3.png`(보고용, 초점 구간마다 하나)
빨강 = 우리 방법(M0, 50% 경계), 하늘색 = 가장 바깥 단(M2)

| 경계 | 보이는 것 | 판단 |
|---|---|---|
| 샤프트 위 | 1~2px 안에 떨어지는 절벽 하나. 빨강·하늘색 거의 겹침(차이 0.0~0.2px) | 제대로 잡음 |
| 핀 위·아래 | 깨끗한 절벽. 두 방법 차이 0~0.5px | 기준(핀)은 제대로 잡음. 핀 위 경계가 핀을 따라 기우는 건 10-11에 확인한 것(`1011_pincol`) |
| **샤프트 아래** | 샤프트 안쪽이 0이 아니라 배경의 0.3~0.4로 밝고(연한 띠), 거기서 "작은 단 -> 급경사 -> 평지(0.85~0.9) -> 배경" 순서의 계단이 약 20~25px(0.7~0.9mm)에 걸쳐 있음 | **"진짜 경계"가 어디인지 사진 안에 답이 없음** |

- 50% 문턱(밝기 약 0.54)이 첫 작은 단 꼭대기(0.4~0.5)와 거의 같은 높이에 걸린다. 그래서 시편마다 빨강이 작은 단 위에 걸리기도 하고(NO2~5, 초점 흐린 F1·F2), 급경사에 걸리기도 한다(NO1·6·8·9·10)
- 빨강과 하늘색의 차이(아래 단 차이)는 시편마다 0.4~3.4px, 즉 15~125µm. 공차 전폭 20µm보다 훨씬 크다
- 멘토 말("아래 연한 띠를 못 잡을 수 있다")은 반만 맞다. 못 잡는 게 아니라, 띠가 있어서 **어느 계단을 잡아도 그게 실제 표면이라는 근거가 없다**

## 2. 오차에 패턴이 있나 (있으면 규칙, 없으면 학습)

규칙은 `pattern.py` 머리에 결과 보기 전에 고정했다. 후보 값 7개, 정상 시편 10개를 하나씩 빼고(LOO) 나머지 9개로 "오차 = a + b x 값"을 맞춰 보정한다.

| 보정 규칙 | 오차와 상관 r | LOO 평균 오차 µm | 최대 µm |
|---|---|---|---|
| (기준) 평균 찍기 — 측정 안 함 | | **5.8** | 12.7 |
| 치우침만 빼기 (기존 M0) | | 15.5 | 37.0 |
| A 아래 단 차이 | -0.22 | 17.7 | 38.9 |
| B 샤프트 안 밝기(연한 띠 높이) | -0.05 | 17.5 | 42.7 |
| **C 아래 흐림 폭** | **-0.69** | **10.8** | 28.0 |
| D 위 흐림 폭(초점) | -0.14 | 17.2 | 41.6 |
| E 앉은 높이 | -0.02 | 16.5 | 37.6 |
| F 배경 밝기 | +0.06 | 17.9 | 37.0 |
| G 초점 구간별 치우침 | | 20.4 | 44.2 |

- **패턴은 약하게 하나 있다.** 아래 흐림 폭(C)으로 보정하면 15.5 -> 10.8µm. 방향은 10-09의 "아래 경계 90->50% 거리 r -0.82"(`1008_field` (72))와 같다
- **하지만 규칙으로는 부족하다.** 10.8µm도 평균 찍기 5.8µm를 못 이기고, 공차 ±10µm에도 못 들어온다. 후보 7개 중 하나라 우연일 몫도 있다. C의 시편 간 차이가 48~51px로 3px뿐이라 새 사진에서 다시 확인해야 한다
- 그림에서 가장 눈에 띈 A(어느 단을 잡았나)는 오차와 거의 상관이 없다(r -0.22). 바깥 단(M2) 자체도 시편마다 움직이기 때문(1008_methods에서 M2 LOO 24.8µm). **아래 경계에는 고정된 기준선이 없다**
- **학습으로도 못 간다.** 학습에는 "이 사진의 진짜 경계는 몇.몇 px" 정답이 필요한데, 아래 경계는 위 그림처럼 사진 안에 답이 없고, 가진 정답은 시편 12개의 지름뿐이다

## 결론 (멘토 틀에 맞춰)

| 멘토 질문 | 답 |
|---|---|
| 경계를 제대로 잡나? | 위·핀은 예. 샤프트 아래는 잡을 "진짜 경계"가 사진에 없다 (계단 20~25px) |
| 패턴이 있나? | 약하게 하나(아래 흐림 폭). 보정해도 10.8µm, 평균 찍기 5.8µm 못 이김 |
| 규칙 / 학습? | 둘 다 지금 데이터로는 ±10µm 못 간다. **먼저 아래 띠를 촬영에서 없애야 한다** (아래 가림 1cm, 근본은 평행광 백라이트). 띠가 없어진 사진에서 이 두 표를 다시 돌리면 된다 |
