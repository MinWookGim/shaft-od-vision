# 10-08 130장, 경계 찾는 방법을 처음부터 다시 비교 (10-11)

`cache.py`(경계 근처만 잘라 저장, 1회) -> `methods.py`(25초). M0 은 예전 값(full_rows.csv)을 소수 둘째 자리까지 그대로 재현.

## 평가 규칙 (결과 보기 전에 고정)
사진마다 지름px/핀px x10 = mm, 시편마다 10장 평균. 정상 시편(묶음 2~10, 13) 하나씩 빼고 나머지로 치우침을 구해 뺀 오차(LOO).
묶음 1(핀 다시 놓기 전)만 제외. NG 는 정상 10개로 교정. 기준선 = 측정 없이 모두 정상 평균으로 찍기.

## 읽는 법
1. **어떤 방법도 "평균 찍기"(5.8um)를 못 이긴다.** 정상 시편 실측이 20.010~20.030 (폭 20um) 안에 몰려 있어서, 측정 오차가 그보다 크면 측정이 정보를 못 보탠다. 09-17 에 09-16 사진으로 낸 결론(정상 구간 측정 정보 0)과 같다
2. 바깥 단 방법(M2~M5)은 초점 구간에 따라 치우친다: 첫 초점 묶음(NO3, NO4) +30~+108, 셋째 초점 묶음(NO7~10) 대부분 음수. 바깥 단 위치가 흐림(초점)에 따라 움직인다는 뜻
3. 2D 직선(M4)은 M2 와 거의 같다. 열마다 잡음은 이미 작아서 직선으로 더 줄 게 없다
4. 위 경계만(M1)은 무너짐: NO10 이 다른 시편보다 약 16px(약 600um) 높게 앉았다. 시편을 놓을 때마다 높이가 달라져서 고정물 기준 거리로는 지름을 못 잰다
5. NG 는 어느 방법도 정상과 못 가른다(M5 가 NG 오차는 작지만 정상 쪽 오차가 +-90um)

## 약한 곳
- 시편 10개 + NG 2개라 방법 사이 순위는 흔들릴 수 있다. 다만 "평균 찍기를 못 이긴다"는 차이가 커서(최선 15.5 vs 5.8) 바뀌기 어렵다
- 평가는 핀 비율 환산 하나만 썼다
