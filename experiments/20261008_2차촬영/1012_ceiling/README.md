# 1012_ceiling — OpenCV(경계 규칙)를 고쳐서 맞출 수 있나 (2026-10-12)

계기: 10-12 저녁 회의에서 선행 개발자 전제 = "촬영 조건이 크게 틀어지지 않으면 OpenCV 수정으로 맞출 수 있다". 이걸 10-08 사진으로 확인한다.

## 방법 (`ceiling.py`, 3초)
- 위·아래 경계 문턱을 각각 10%~90%(9단계)로 바꾼 81개 규칙. 형태학 전처리 7가지도 결국 경계가 걸리는 높이를 옮기는 일이라 이 가족이 대부분 덮는다.
- 시편 12개(정상 10 + NG 2) 10장 평균을 핀으로 mm 환산.
- **정답을 보고 규칙을 고른다**(낙관적 상한). 그래도 안 되면 이 사진에서 규칙으로는 안 된다는 뜻.
- 우연 기준: 실측을 시편끼리 섞어 같은 고르기를 5000번.
- 확인: tu0.5/tl0.5 = 기존 M0 = LOO 15.5um 재현.

## 결과 (`result.txt`)
| | 값 | 기준 |
|---|---|---|
| 정답 보고 고른 최선 상관 r | +0.59 | 섞은 실측으로도 95%가 +0.74까지 나옴 (p=0.19) |
| 측정이 제대로면 기대 r | 약 0.94 | 실측 sd 10.5, 10장 평균 흔들림 3.9um로 계산 |
| 정답 보고 고른 최선 LOO MAE | 13.7um (NG1 +19) | 평균 찍기 5.8 |

- 81개 중 어느 것도 우연보다 낫지 않다. 측정이 정보를 담았다면 r 0.9 근처가 나와야 하는데, 이 시험은 그걸 볼 힘이 있다.
- 위 문턱은 거의 상관없고(행끼리 같음) **아래 문턱 하나가 r을 −0.47~+0.59로 흔든다**. 정보는 아래 경계에서 살고 죽는데, 아래 경계에는 사진 안에 정답이 없다(`1012_edgecheck`).
- 10장 평균 흔들림(3.9um)이 아니라 시편마다 남는 치우침(약 13um)이 문제. 사진 장수·평균으로 안 줄어든다.

## 결론
- 10-08 사진에서는 경계 규칙(OpenCV)을 어떻게 고쳐도 지름을 못 읽는다. 선행 개발자 7가지 결과(변화 0.3px)와 맞다.
- 남은 가능성은 사진을 바꾸는 쪽(아래 경계 빛: 필름·평행광·조리개, 기준 샤프트 대조) = 하드웨어·촬영 조건. 선행 개발자 전제의 앞부분("촬영 조건이 틀어지지 않으면")을 다음 촬영이 시험한다.
- 한계: 이 데이터 한 번, 시편 12개. 학습(ML)은 정답이 시편 12개 지름뿐이라 이 판정 밖이지만 같은 이유로 어렵다.
