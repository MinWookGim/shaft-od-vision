# 1011_pincol — 핀게이지를 열마다 측정 (10-08 130장 전체, 2026-10-11)

사진 한 장에서 본 "핀 px가 V블록 끝 그림자 쪽 열에서 커진다"를 130장 전체로 확인했다.

**방법**
- 열 9450~9900을 4px 간격으로 측정했다. 한 열은 5열 평균이다.
- 각 열에서 위·아래 경계를 찾았다. 50% 밝기 규칙으로, 10-08 분석과 같다.
- s = 핀 왼쪽 끝에서 떨어진 거리(px).

## 결과

### 1. 핀 폭은 핀 전체에 걸쳐 오른쪽으로 갈수록 커진다. 움직이는 건 위 경계뿐이다

130장 평균이다(`_out/pin_profile.png` 왼쪽).

```
s  20~ 39 : -0.62px
s  60~ 79 : -0.23px
s 100~119 : +0.09px
s 140~159 : +1.27px
s 160~179 : +1.96px   -> 핀 길이 약 140px 동안 약 2.6px (약 1%) 커짐
```

- 위 경계 기울기는 13묶음 전부 100px당 -1.3~-1.7px다. 오른쪽으로 갈수록 위로 올라간다.
- 아래 경계 기울기는 -0.14~+0.24px로 거의 평평하다.
- V블록 끝 근처에서만 생기는 일이 아니다. 핀 전체에 꾸준히 있고, 오른쪽 끝(s 140 이후)에서 가팔라진다.

**원인은 확정하지 못했다.** 가능성을 하나씩 따지면 이렇다.
- 핀이 화면에서 기울었다면 위·아래 경계가 같은 방향으로 움직여야 한다. 그렇지 않았다.
- 핀 한쪽 끝이 카메라에 더 가까운 원근이라면 위·아래가 반대 방향으로 같은 만큼 벌어져야 한다. 그렇지도 않았다.
- 위 경계만 움직이니 조명·반사 쪽을 의심한다. 핀 위의 V블록 끝 그림자, 위쪽 빛이 스치는 반사가 후보다.

### 2. NO1·NO2에서는 핀(과 V블록)이 약 40px 왼쪽에 있었다

| 묶음 | 핀 왼쪽 끝 xL | 측정 가능 끝 xR |
|---|---|---|
| 1 | 9550 | 9730 |
| 2 | 9562 | 9726 |
| 3\~13 | 9594\~9602 | 9758\~9766 |

열 9655~9700으로 고정해 측정하면, NO1·NO2에서는 핀의 더 오른쪽 부분을 측정한 셈이다. 그 부분은 폭이 더 넓다.

### 3. 핀 위 같은 자리를 측정하면 나아진다. 하지만 평균 찍기는 여전히 못 이긴다

| 핀 측정 자리 | 지름 LOO MAE / 최대 (µm) | NG1, NG2 | F1 안 묶음 간 핀 폭 범위 | 같은 묶음 핀 sd |
|---|---|---|---|---|
| A 고정 열 9655~9700 (기존) | 15.2 / 37.9 | +48, +71 | 1.11px | 0.10px |
| **B 핀 위 같은 자리 s 60~105** | **12.8** / 44.1 | +47, +70 | **0.71px** | 0.09px |
| C 핀 왼쪽 s 25~70 | 14.8 / 39.8 | +49, +74 | 0.63px | 0.12px |
| (기준) 평균 찍기 | 5.8 / 12.7 | | | |

- 같은 자리를 측정하자 NO2 오차가 -24에서 +4µm로 줄었다. F1 안의 핀 흔들림도 1/3쯤 줄었다.
- 그래도 MAE 12.8µm로 평균 찍기 5.8µm를 못 이긴다. NG 판별도 그대로다.
- 남은 F1 흔들림(NO2 269.85 vs NO4 269.14)은 핀 자리로 설명되지 않는다. NO3와 NO4는 핀 자리가 같다.
- F3로 넘어갈 때의 +1.3px 점프는 그대로다. 재초점 때문이다.

## 결론
- 사진 한 장에서 본 것은 **맞았지만 범위가 달랐다.** V블록 끝 근처만이 아니라 핀 전체에 걸친 기울기였다.
- 핀 측정 자리는 **실제 오차원**이다. 핀 위 같은 자리를 측정하는 쪽으로 고치는 게 맞다.
- 하지만 **실패의 주원인은 아니다.** 고쳐도 지름 측정은 평균 찍기를 못 이긴다.
- 다음 촬영에서 할 일:
  - 핀 놓는 자리를 표시해 고정한다.
  - 핀을 V블록 끝에서 띄운다.
  - 측정 코드는 핀 왼쪽 끝 기준 같은 자리를 측정하게 바꾼다.

## 덧붙임 — 기록에 없던 이동 하나 (같은 날)
핀 왼쪽 끝 xL과 측정 가능 끝 xR(V블록 끝 그림자)을 같이 보면, 핀이 움직인 일이 두 번 있었다.
- NO1 → NO2: xL만 9550에서 9562로 바뀌고, xR은 9730에서 9726으로 거의 그대로다. 핀만 다시 놓았다. 현장 기록(LOG 70)의 "1번 시편 후 핀 다시 놓음"과 맞는다.
- NO2 → NO3: xL과 xR이 함께 약 40px 오른쪽으로 갔다. 핀과 V블록이 통째로 움직였다. **현장 기록에 없는 이동**이다. 분류표는 NO2부터 같은 배치 P2로 묶었지만, 실제로는 NO2와 NO3 이후가 다른 배치다.

### 정정 — V블록이 아니라 카메라가 움직였다
팀장 확인: V블록이 통째로 움직인 적은 실제로 없다. 그래서 `shift.py`로 사진 속 고정물(왼쪽 V블록·자, 오른쪽 V블록, 백라이트 아래 테두리, 핀 주변)을 NO3 첫 장과 비교했다(위상상관). 결과는 `_out/shift.txt`.
- NO1·NO2는 네 영역 모두 가로 −36~−60px다. 사진 전체가 같이 옮겨졌으니 **카메라(폰)가 약 40px 밀렸다.** 위의 "핀과 V블록이 통째로 움직였다"는 틀린 해석이다. 핀 끝과 V블록 끝 두 점만으로는 물체 이동과 카메라 이동을 구별할 수 없었다.
- NO1과 NO2 사이에도 카메라가 10~15px 차이 난다. 핀 다시 놓기에 카메라 차이가 겹쳤다.
- 현장 폰 고정 확인(연속 3장 0.35px)은 시편 교체 사이의 이동을 잡지 못한다.
- 덤: NO7 이후에는 왼쪽 영역 −10px, 오른쪽 +4px다. 가운데 기준으로 화면이 약 0.2% 커졌다. 재초점 배율 변화와 같은 방향이다(핀 +0.5%).
