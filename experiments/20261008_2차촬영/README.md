# 10-08 2차 촬영 분석 코드 (10-09 ~ 10-12)

[2차 촬영 분석 정리](../../docs/05_meetings/2026-10-12_2차촬영_분석정리.md)와 [7가지 수정 적용 결과](../../docs/05_meetings/2026-10-12_7가지수정_적용결과.md)의 숫자를 만든 코드와 결과 파일이다. 참고용으로 올린다.

- 사진 원본(2억 화소 130장)과 중간 캐시(`*.npz`, `*.npy`), 그림(`*.png`, `*.jpg`)은 올리지 않았다. 그래서 그대로는 안 돌아가고, 코드와 결과(`_out/`, `result.txt` 등)를 읽는 용도다
- 사진 경로는 `../../field/photos/20261008_원전기계/full_result` 기준으로 적혀 있다(작업 폴더 기준)
- 선행 엔진(`shaft_core.py`)을 쓰는 스크립트는 환경변수 `SHAFT_CORE_DIR`로 엔진 폴더를 지정한다
- 폴더마다 README가 있는 것은 그 README에 질문·방법·결과·약한 곳이 있다

## 순서와 문서 대응
| 폴더 | 질문 | 분석 정리 |
|---|---|---|
| `1008_field` | 130장 기본 측정(50% 경계), 베어링부 박스 자동 탐지. `_out/full_rows.csv`가 이후 모든 분석의 사진 목록·실측 | 1·2절 |
| `1008_engine` | 선행 엔진을 10-08 사진에 돌리면 어떻게 나오나(옵션 A~F) | 5절 재현 |
| `1008_methods` | 경계 찾는 방법 6종(M0~M5)을 같은 규칙으로 비교, 평균 찍기 기준 5.8µm | 2·3절 |
| `1011_camstate` | 카메라 이동·초점 흐름을 고정물로 측정 | 4절 |
| `1011_pincol` | 핀 측정 자리(핀 폭이 핀을 따라 변함) | 4절 |
| `1011_res50` | 50MP로 줄여도 같은가(2배·4배 축소) | 4절 해상도 |
| `1012_edgecheck` | 경계를 눈으로 확인, 오차 패턴 | 4절 |
| `1012_ng_apply` | 선행 교정식을 NG1·NG2에 적용 | 5절 |
| `1012_seven` | 코드 수정 방향 7가지, 선행 박스·Anchor 비교 | 5절, 7가지 문서 |
