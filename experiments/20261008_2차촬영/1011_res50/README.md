# 1011_res50 — 프로 모드 50MP로 가면 얼마나 잃나 (10-08 사진을 줄여서 시험, 2026-10-11)

계기: 팀장 확인으로 S26 울트라 프로 모드(수동 초점)는 50MP까지만 된다. 10-08은 2억 화소 자동 모드였다(1px 약 37µm).
수동 초점을 쓰려면 해상도가 가로세로 절반(1px 약 74µm)이 된다. 그만큼 측정이 나빠지는지 본다.

방법 (돌리기 전에 고정)
- 10-08 130장 경계 근처 자른 것(`1008_methods/_out/cache.npz`)을 k x k 화소 평균으로 줄였다. k=2가 50MP, k=4가 12.5MP 상당이다.
- 측정·평가는 `1008_methods`와 같다. 핀 비율, 핀 열 9655~9700, 정상 10개 LOO, 기준선 = 평균 찍기 5.8µm.
- 노이즈 바닥: 같은 k=2에서 묶는 격자를 세로·가로로 1px 옮겨 다시 측정했다(`phase.py`). 정보량은 같으니 이 차이는 우연이다.

## 결과 (`result.txt`, `phase.txt`)

| 해상도 | 방법 | LOO MAE / 최대 (µm) | 같은 시편 10장 흔들림 | NG1, NG2 |
|---|---|---|---|---|
| 200MP 그대로 | M0 50% | 15.4 / 37.3 | 8.2µm | +49, +72 |
| **50MP 상당 (4가지 격자 위치)** | M0 50% | **15.5 ~ 17.4** / 42.6 ~ 49.1 | 8.8µm | +49, +56 |
| 12.5MP 상당 | M0 50% | 33.8 / 74.0 | 13.7µm | +34, +52 |
| 200MP 그대로 | M2 바깥 단 | 24.7 / 68.7 | 8.2µm | |
| 50MP 상당 | M2 바깥 단 | 32.8 / 82.0 | 11.2µm | |
| (기준) 평균 찍기 | | 5.8 / 12.7 | | |

- **M0 기준으로 50MP는 200MP와 구별이 안 된다.** 15.4 대 15.5~17.4이고, 격자만 옮겨도 15.5~17.4로 흔들린다.
- 12.5MP까지 내리면 확실히 나빠진다(33.8). 그러니 해상도가 아무 상관 없는 건 아니다. 2배까지는 괜찮고 4배는 안 된다.
- M2는 50MP에서 나빠졌다(24.7 -> 32.8). 다만 M2는 원래 M0보다 나쁜 방법이라 판단에 쓰지 않는다.
- 어느 쪽도 평균 찍기를 못 이기는 건 그대로다.

## 덤 — 격자를 1px 옮겼을 뿐인데 시편별 오차가 크게 바뀐다

```
위상(0,0): -2 +31 +29 -2 -4 -43  +5 -25 -10 +22
위상(1,0): -8 +17  +3 -9 -12 -48 +27 +18  +3  +8   (세로 1px 이동)
위상(0,1): 가로 이동은 거의 그대로
```

- 세로로 1px만 옮겨도 NO9가 -25에서 +18로, NO4가 +29에서 +3으로 바뀐다. 가로 이동은 영향이 없다. 경계가 가로로 누워 있으니 맞는 결과다.
- 같은 시편 10장은 카메라가 그대로라 격자 위치도 그대로다. 그래서 10장 흔들림은 작은데, 시편이 바뀌면 경계가 화소 격자에 걸치는 위치가 달라진다.
- **가설:** 카메라가 안정했던 구간에도 남은 ±13µm 일부는, 여러 단으로 된 경계 모양(아래 경계 반사 단)과 화소 격자의 위치 관계에서 올 수 있다. 50% 문턱이 단 사이를 건너뛰는 식이다.
- 약점: 이건 줄인 사진에서 본 것이다. 원본 해상도에서도 같은 크기로 일어나는지는 이 데이터로 확인할 수 없다. 원본에서 확인하려면 사진을 아주 조금씩 옮겨가며 찍은 같은 시편 사진이 필요하다.

## 결론
- **프로 모드 50MP + 수동 초점으로 가도 해상도 손해는 이 데이터로는 보이지 않는다.** 초점 흐름(NO7 +69µm)과 폰 조작으로 인한 카메라 이동을 없애는 이득이 더 크다.
- 줄인 사진은 실제 50MP보다 불리하다. 실제 50MP는 화소 4개를 합쳐 읽어 잡음이 적다. 그러니 이 결과는 50MP에 대해 보수적이다.
- 다만 공차 안 측정을 막는 건 해상도가 아니라 경계 모양(시편 쪽)이라는 판단은 그대로다.
