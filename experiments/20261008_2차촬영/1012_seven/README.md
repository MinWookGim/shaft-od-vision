# 1012_seven — 선행 개발자 "코드 수정 방향 7가지"를 돌려봄 (2026-10-12)

원문(docx·png)은 기법 이름만 있고 커널·문턱이 없다. 그래서 내가 정해서 구현했다(`seven.py` 맨 위, 결과 보기 전에 고정). 커널 세로 25px, 띠 문턱 밝기 25.
엔진 = 선행 엔진 F 설정(가장 센 쌍, 박스 안 넓힘). 보고서 px를 0.1px 안에서 재현하는 경로다(`1012_ng_apply`).
측정 박스는 `cache.py`로 잘라 둔 것(`crops.npz`).

## 덧붙여 본 것
- docx 끝의 "전체적으로는" 숫자(Bias +0.002343, MAE 0.002343, 최대 0.004647, 40/40)는 V2 보고서 숫자와 소수 여섯째 자리까지 같다. 7가지 적용 뒤 결과인지, V2 숫자를 다시 붙인 것인지 확인이 필요하다. 내 구현에서는 2~7 적용 시 MAE가 2.1 -> 2.0으로 거의 그대로였다.

## 약한 곳
- 커널·문턱은 내가 정했다. 선행 개발자 실제 코드와 다를 수 있다. 다만 결론(띠 제거는 바깥 경계를 안 바꾸거나, 바꾸면 전체를 한쪽으로 옮긴다)은 커널 크기에 크게 안 달려 보인다. 선행 개발자 코드를 받으면 같은 표로 다시 돌린다.
