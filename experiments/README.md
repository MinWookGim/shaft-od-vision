# experiments

실험 코드. 스크립트 하나 = 질문 하나. 파일명에 날짜와 질문을 붙인다 (예: `20260916_native_scale.py`).
실행 출력은 `results/` 에 날짜 붙여 그대로 둔다. 요약은 `docs/02_facts.md` 로.

현재 측정 엔진(YOLO ROI + OpenCV 엣지)은 선행 저장소(`Shaft_OD_Measurement`)의 것을 쓴다. 이 저장소에는 그 위에 얹은 실험 스크립트만 둔다.

- `20261008_2차촬영/`: 10-08 2차 촬영 분석(10-09 ~ 10-12). 사진·캐시 없이 코드와 결과만, 참고용
- `20261021_3차촬영/`: 10-21 3차 촬영 분석(10-21 ~ 10-23). 사진 없이 코드·결과 csv·캐시만, 참고용
- `20261026_거칠기/`: 업체 거칠기 12개와 3차 시편별 치우침 대조(10-26)
