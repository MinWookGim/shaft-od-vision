## 지금 어디까지 왔나 (2026-10-12)

- 10-08 원전기계 2차 촬영 130장(정상 10 + NG 2 + NO1 재촬영, 시편마다 10장)
- 경계 찾는 방법 6종 모두 "평균 찍기"(측정 없이 정상 평균을 부른 오차, 5.8µm)를 이기지 못했다
- 원인: 시편 교체 때 카메라 이동·초점 흐름, 샤프트 아래 경계의 빛 넘침(여러 단), 시편 놓임
- 선행 결과보고서(MAE 2.34µm)는 같은 사진으로 재현된다. 다만 같은 나누기에서 평균 찍기도 3.5µm이고, 같은 교정식으로 NG1·NG2 20장이 전부 OK로 나온다
- 코드 수정 7가지와 Anchor로는 결과가 거의 바뀌지 않았다
- 미결: 다음 촬영 시나리오, 내부 기준(측정 항목·기준값), 기준 샤프트, 최종 보고서 범위 ([회의록 10-12](docs/05_meetings/2026-10-12_회의록.md))
