# shaft-od-vision

스마트폰 사진으로 자동차 조향 샤프트의 외경(Ø20.020 ±0.010mm)을 재고 합격·불합격을 가를 수 있는지 시험한 프로젝트의 **분석 저장소**다.
모두의연구소 아이펠(AIFFEL) 365챌린지, Precision 365 팀(김민욱·조희연·이다겸), 2026-09 ~ 11.

## 결론 (세 줄)

- **판정은 못 했다.** 촬영 전에 정한 규칙(교정 시편 3개 → 평가 7개)으로 사진 오차는 평균 7.9µm, 사진 없이 교정 시편 실측 평균만 불러도 6.4µm였다.
- 사진 한 장의 경계는 0.1px(약 3µm)까지 반복됐다. 막은 것은 해상도가 아니라 **촬영 중 경계가 흐려지는 변화**(움직이지 않는 기준 핀이 18분 동안 -0.18%)와 **시편별 치우침**이었다.
- 원인별 오차를 합치면 약 12µm, 이 공차를 가르려면 1µm가 필요하다. 다음 시스템은 이 오차 예산에서 시작한다.
