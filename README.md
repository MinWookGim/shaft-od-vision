## 구조

```
docs/
  00_charter.md        팀 차터. 경계·산출물 귀속
  01_problem.md        문제 정의·목표·범위 밖
  02_facts.md          원자료를 직접 열어 확인한 것만
  03_claims.md         아직 추정인 것. 근거가 생기면 facts 로 옮긴다
  04_decisions/        D-001, D-002 ... 한 결정에 파일 하나
  05_meetings/         날짜별 회의·현장 기록
  멘토질문_*.md        멘토링 질문 초안
experiments/           실험 코드. 스크립트 하나 = 질문 하나
  results/             실행 출력을 날짜 붙여 그대로
src/                   최종 파이프라인
reports/               중간·최종 보고서, 발표 자료 (검출 문턱 산출 근거)
data/                  README 만. 사진·녹음은 저장소에 넣지 않는다
```

매일 만지는 건 셋이다: `docs/02_facts.md`, `experiments/`, 이 README.

## 규칙

- 숫자는 `02_facts.md` 한 곳에서만 인용한다. 보고서에서 새로 계산하지 않는다
- 확인 안 된 것은 `03_claims.md` 에 둔다. 추정을 facts 에 쓰지 않는다
